《年初还不会写代码，几个月做出25万美元年收入：Replit CEO把AI编程这本账算清了》

2023年9月，投资人 Sarah Guo 和 Elad Gil 的播客 No Priors 请来 Replit 联合创始人兼 CEO 阿姆贾德·马萨德（Amjad Masad），他的头衔还有一截：首席工程师。开场就有个扎眼的案例：一位创业者今年年初还不会写代码，几个月后做出了年收入 25 万美元（ARR）的生意，全程用 Replit 和它的 AI 套件 Ghostwriter 完成。

Replit 目前有超过 2200 万用户，最近刚和 Google 达成合作。这期对话信息密度很高：AI 编程到底提升多少生产力、Replit 为什么非要自己训模型、扎克伯格开源 Llama 背后的商业算盘，还有一个相当大胆的设想，让 AI 智能体在你睡觉时替你赚钱。马萨德对时间表的拆解尤其值得记下来：哪些事 6 到 18 个月内就会发生，哪些要等三到五年。

没有笔记本电脑的大学生，和一篇把代码变成「语言」的论文

马萨德和编程环境的较劲从大学就开始了。他对编程语言着迷，但每次写代码都要折腾开发环境，烦得不行，关键是他连笔记本电脑都没有。他的想法很朴素：为什么不能打开浏览器就写代码？查了一圈发现没人做，就自己动手。

第一版原型就是一张网页，一个文本框，一个写着「运行」的按钮。同学们喜欢得不得了，都用起来了。这个形态到今天依然是 Replit 的骨架。后来他做出一项突破：率先把 Python、Ruby 这些语言编译成 JavaScript，让代码直接跑在浏览器沙箱里。项目开源后，他靠它拿到 Codecademy 创始工程师的职位。这段经历让他对「处理代码的代码」有了手感，也为后来押注 AI 编程埋了伏笔。

之后他去 Facebook，成为 React Native 的创始工程师之一，参与过 React、Jest、Babel 这些今天 JavaScript 开发者天天在用的工具。团队的目标是让移动开发像 Web 开发一样快、一样爽，他认为做到了。2016 年他出来创办 Replit，因为他发现当时的在线编辑器都不够「Web 原生」，做不到像 Figma 或 Google Docs 那样，甩一个链接过去，对方点开就能跟你一起写代码。Replit 补的就是这块。

给他方向定调的是 2012 年的论文《On the Naturalness of Software》。一批研究者把自然语言处理的方法搬到代码上，发现代码和自然语言一样高度重复，完全可以当语言来建模，一个基础的 N-gram 模型就能生成可编译的代码。论文标题里的「自然性」说的就是这个。代码的重复性意味着语言模型天然适合处理它，这个判断比 ChatGPT 早了整整十年。

之后每隔一两年，他都会去查一遍「机器学习写代码」的最新水平，一直没起色，直到 GPT-2 出现。微调后的 GPT-2 写代码「还算凑合」。GPT-3 一出，他知道时候到了，开始做后来命名为 Ghostwriter 的产品。最初是一堆散落在编辑器里的小工具，解释代码、生成代码，后来加上类似 Copilot 的自动补全和聊天功能，凑成完整的 AI 套件。

Elad Gil 在节目里感叹，带上下文的代码补全已经被广泛接受为改变工作流的产品，Replit 和 GitHub Copilot 是少数几个跑出来的。马萨德的回应很冷静：这类工具依然非常原始，transformer 用在代码上的潜力远没挖完。

新手先吃红利，职业程序员的 10 倍还在路上

生产力到底提升多少？Replit 研究过自家产品的使用数据，结论是：对职业程序员，AI 让「写代码」这个动作本身提速 30% 到 50%。注意范围，这只是编码环节。调试、部署、开会、把需求文档翻译成代码，这些围绕编程的活儿，AI 还没碰。马萨德认为 AI 最终会吃遍软件开发生命周期的每一环。

这里有个容易被忽略的细节。30% 到 50% 听起来不算革命，但编码只占工程师工作的一部分，需求评审、调试、上线、运维加起来占掉大半时间。换句话说，现在测到的提升，只是这场变革最先发生的那一小块。

但当下拿到最大红利的是新手。初学者现在就有 2 倍、3 倍甚至 10 倍的生产力倍增。学一点代码，配上 AI，就能做出年收入二十多万美元的产品，开头那个案例就是这么来的。马萨德说，现在从 Replit 获得最多价值的，恰恰是那些原本没有技能去创业的人。

职业程序员的大幅跃升什么时候来？Elad 把问题抛得很直接，他的回答分两层。第一层，就算模型能力原地踏步，只把基础设施补齐，6 到 18 个月内就能看到像样的智能体体验。用他的话说，现在还处在「GPT 模型的演示时代」，demo 看着惊艳，真要交付还得人肉兜底，差距就在基础设施上。Replit 正在容器内部建一套服务，让 AI 能读文件、写文件、装依赖包、执行代码、克隆项目，这大概率还要多个模型协作。这些能力凑齐之后，你给 AI 一个高层任务，比如「做一个登录页」，它就能交出一个能当起点的成品。

第二层是模型本身的进步。上下文更长、性能更强、价格更低，甚至出现全新的训练方法，这些叠加起来，三到五年内软件开发可能整个变样。他给的画像是：程序员会更像工程经理，手下的「员工」主要是 AI，大部分时间在审查代码、下指令，敲键盘的时间被压缩到很小一部分。

主持人 Sarah 提到她基金支持的一场大学生黑客松，MIT 的学生自己设计制造 GPU，却普遍认为以后不需要像过去那样学编程，调试可以交给「另一个 agent」。马萨德从这些回答里读出一种态度：如果 AI 搞不定，我就去学。黑客的正确姿势是按需学习，先想清楚要造什么，再倒推需要什么技能。有了 Ghostwriter，他自己的学习路径也能一步跨过 20 个台阶。

被产品逼出来的自研模型，30 亿参数刚刚好

Replit 为什么要自己训模型？答案很实际：商业 API 撑不起产品。马萨德解释，微软拿到 GPT-3 后做了蒸馏，部署在自己的基础设施上，再加大量缓存，又快又便宜。普通开发者只能调 API，贵、慢，还没法做这些优化。更麻烦的是，OpenAI 现在只出聊天模型，不再提供补全（completion）模型，想做自动补全产品，靠商业 API 几乎走不通。

他们试出来的甜点位是 30 亿参数：10 亿参数「太笨」，30 亿够聪明，同时推理够快、托管够便宜。赶上 Chinchilla 论文发表、LLaMA 公布的节点，「小模型多喂 token」的思路正当红。他们把开源语料全用上，训出基础模型并开源，理由是训练数据来自开源社区，理应回馈。再混入 Replit 自家数据继续训练，性能比开源版又提升了 50%。这个 30 亿参数的小模型，当时胜过多数开源代码模型，包括体积大它 20 倍的。

但马萨德对开源圈的风气有意见：

很多创始人把训模型当成荣誉和身份象征。我们发布 30 亿参数模型后，三四个模仿者马上冒出来，大家争抢无聊的跑分。正确的顺序是从产品和用户需求出发，再去解决路上的技术难题。现在能用 Llama 我们就用 Llama，必须自己训我们才训。

他给扎克伯格提的方案，和 Llama 身上的三样东西

2022 年初，马萨德意识到商业 API 做不出想要的产品，一度很沮丧：Replit 资金不多，难道这类产品只有微软做得出来？他约到了扎克伯格，当面提了一个类比。

故事要从 Open Compute 项目说起。Google 和 AWS 把数据中心技术捂得死死的，因为它们卖云。Facebook 不卖云，云对它是互补品。于是 Facebook 拉上一批同样不卖云的公司，把数据中心硬件设计开源共享，大获成功。马萨德对扎克伯格说：把这套打法复制到 LLM 上，开源 AI 对 Meta 是互补品，能让你做出更好的产品，这是经典的「商品化你的互补品」策略。扎克伯格当时点了点头。后来 Meta 果然这么干了，扎克伯格在采访里也拿 Open Compute 类比 Llama。

让马萨德意外的是，行业的响应寥寥。他的判断是，AI 安全议题让很多公司不敢沾开源模型，怕被贴上「输出有害内容」的关联标签。而且发布开源大模型需要胆量，Meta 正承受政治压力。他的原话很直白：「这个行业缺的就是胆量，而扎克伯格有。」

Elad 补了一个历史视角：每一波重要的开源软件背后几乎都有大公司赞助。Linux 曾被 IBM 以每年约 10 亿美元的规模赞助过一段时间，WebKit 背后站着 Google 和 Apple。他还说，这个生态里钱是有的，真正稀缺的是人才。Meta 罕见地凑齐了三样东西：胆量、资本、人才。如果 Meta 退出，短期内很难找到替代者。

马萨德补了一个技术层面的担忧：如果模型架构越来越复杂，比如混合专家架构加上有状态组件，开源难度会陡增。工具容易开源，就是一个能跑的二进制文件；复杂系统就难了。长期看开源模型终会追平商业模型，但当下的格局确实难说。

悬赏、钱包，和睡觉时替你赚钱的 AI

Replit 产品里有个悬赏市场 Bounties，开发者接单赚钱。马萨德的初衷是，平台上散落着世界各地正在学编程的人，非洲、印度、泰国、塞尔维亚，他们没有简历，找不到传统工作，但水平在快速涨。悬赏既让他们赚到钱，也验证了他的判断：「懂一点代码的人加上 AI」就是性价比极高的开发者。现在去 Replit 发一个创业项目原型或 MVP 的需求，最低 50 到 100 美元就有人接。

悬赏是第一步，背后是更大的野心。马萨德认为开源世界的货币是 GitHub 星标，一种「假货币」，制造了一堆怪异的副作用。软件经济缺一种原生的价值交换货币。如果开发环境和部署环境内置钱包和交易，你可以把函数、组件、服务发布到网络上按调用计费，别人的应用挂着钱包，用谁的功能就付钱给谁。钱是一种协调机制，能玩出很多花样。

AI 是这个图景的关键变量。现在的 AI 是副驾驶，预测你的下一步。等智能体能半自主行动，它们也应该能花钱和赚钱。马萨德设想了一种「全自动赏金猎人」：造一个 AI，在你睡觉的时候替你接活赚钱。这个设想还带来数据红利：代码训练数据里一直缺「完整产品需求文档到最终成品」的端到端配对，悬赏市场恰好能生产这种数据。

这也接上了 Elad 的问题：2200 万用户是不是训练数据的护城河？他还提到 Google 最近一篇论文，对比人类反馈和 AI 反馈的强化学习，效果大致打平。马萨德的回答很克制，数据护城河容易被高估，真正的优势是端到端平台：从第一行代码，到部署，到生产环境的崩溃日志，再到修改，整个反馈闭环都在一个地方。这个闭环在别处被切分在 GitHub、VS Code 和 AWS 三家手里。有了它，才能拿到覆盖大动作空间的训练数据。

至于支付轨道，他很务实：Stripe 能解决就用 Stripe，需要比特币就用比特币。他设计悬赏时借鉴了以太坊社区的质押思路：接单前先质押 100 美元，承诺五小时交付，每超一小时扣一定比例保证金，谁对自己信心足、赌注下得大，谁就拿到任务，协调半自动完成。他长期看好比特币，认为它会成为「货币的 TCP/IP」。节目里还有个轻松的段子：Stripe、Square 和比特币几乎同一年诞生，两位主持人开玩笑说，中本聪其实是杰克·多西和帕特里克·科里森在合伙干活。

明天就能用上的三件事

  • 如果你是编程新手，现在是窗口期。AI 对新手的倍增效应最大，别等「学完」再动手，直接做一个真实的小项目。一个 MVP 的市场价已经卷到 50 到 100 美元，验证一个想法的成本从未这么低。
  • 评估 AI 编程工具时，别只看写代码环节。30% 到 50% 的提升只覆盖编码本身，调试、部署、需求转代码的自动化是下一波。选工具优先考虑能覆盖完整闭环的平台。
  • 按需学习，倒推技能树。先想清楚要造什么，再决定学什么。AI 搞不定的部分，到时候再学也来得及，这是黑客的标准姿势。
