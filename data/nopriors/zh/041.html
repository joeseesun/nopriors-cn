《70亿参数跑进 MacBook，Mistral CEO 把 AI 的成本账重算了一遍》

2023 年 9 月，一家成立不到半年的巴黎公司放出一个 70 亿参数的开源模型，Apache 2.0 许可，商用免费。这个叫 Mistral 7B 的模型小到能跑在一台 MacBook Pro 上，却改写了很多人对小模型能力上限的判断。

这期 No Priors 的嘉宾是 Mistral AI 的 CEO 兼联合创始人 Arthur Mensch，主持人 Sarah Guo 和 Elad Gil 都是投资人。三个人把话题从创业动机一路聊到安全争论，中间藏着几笔大多数人没算过的账。

Mensch 的履历得先交代。他在机器学习领域干了十年，加入 DeepMind 时，那家实验室的大语言模型团队只有 10 个人。LLM 历史上被引用最多的论文之一 Chinchilla，他是共同作者。2023 年年中，他和 Guillaume Lample、Timothée Lacroix 一起离开 DeepMind 创办 Mistral，节目播出时公司刚满半年。

面对 OpenAI 和 Google 堆起来的美元和 GPU，三个人的团队为什么敢正面进场？Mensch 的解释很朴素：三个人都算这个领域的早期玩家，十年经验让他们知道怎么用更少的算力和预算做出好模型。更直接的原因是，原来所在的公司走向了他们加入时没预料到的方向，他们想在欧洲做一家独立公司，做前沿 AI，把开源写进核心价值。

在 DeepMind，他做的第一个项目叫 RETRO，检索增强模型，和同事 Sébastien Borgeaud 合作，思路是把外部数据库接进预训练，知识可以随时查，没必要全部塞进参数，困惑度实打实降了下来。这个方向当年很冷门，如今检索增强已是主流。第二个项目源于他的博士后方向，最优传输，一个解决「把一堆 token 分给一堆设备、保证每台设备别吃太多」的数学框架，正好拿来搭稀疏混合专家架构。他顺着往下做，又把缩放定律从稠密模型扩展到带专家数量的版本，用来预测性能随规模、专家数、数据量的变化。

再往下，就是 Chinchilla。

Chinchilla 的教训：模型练小一点，反而更值钱

Chinchilla 的核心发现一句话能讲完：2020 年之后，全行业都在用太少的训练数据喂太大的模型。2020 年那篇定调子的缩放定律论文执行得不好，大家照着它把模型越堆越大，token 却没跟上。

Mensch 的解释是，模型无限大、数据有限，不合理；模型有限、数据无限，也不合理，两者之间必然存在比例关系，团队用实验把它找到了。同样的算力预算，按新配方训练，模型更强，推理成本还便宜 4 倍。纯赚，所以整个行业采纳得飞快。

但他认为 Chinchilla 还没走到头。LLaMA 证明了模型可以压缩，Mistral 7B 证明了离压缩极限还很远。把模型做小、做便宜、做快，小到 MacBook Pro 能跑，同时好用到能干活，这是这家新公司交出的第一份成绩单。

为什么盯着推理成本不放？Mensch 拆了一笔账。训练像一次性装修，推理是每天的水电费。2021、2022 年那批冲性能的实验室不在乎水电费，模型跑完一次基准就封存。一旦要部署、要支撑下游应用，电费就成了核心问题。Elad 补充，用户日常花钱的大头就在推理，推理成本主要由模型大小决定，Mistral 7B 直接改写了大家的心智模型。推理成本和训练成本怎么权衡，取决于业务，而一家打算活下来的公司必须把推理做到极便宜，便宜到 Agent 可以到处跑、每个场景都用得起。今天最大的模型恰恰卡在这里。

那还训不训更大的模型？答案显然是。70 亿参数不是终点，模型尺寸对应的能力上限被大家低估了，想要更强的推理能力，就得往大了做。另一层关系更微妙：大模型是造小模型的前提，蒸馏、合成数据，都得先有大模型，才能反哺出更强的小模型。Mistral 的大模型已经在训了。

数据这块，他分得很清楚。预训练要的是最纯净的知识，数据质量直接决定模型好坏，Mistral 在这里下了重注。指令微调和对齐是另一回事，需要人工或机器标注，他坦承这不是 Mistral 当下的强项，团队正在爬坡。

为什么死磕开源：十年一轮的开放与封闭

Mensch 回溯了机器学习这十年。从只能分猫狗的图片分类器，到看起来接近人类智能的模型，靠的是学术界和工业界几十个实验室各自花钱、几乎完全透明地交流。2020 年之前，竞争对手的工作也照发 NeurIPS、ICML，每半年聚一次，想法流通，所有人都在别人的成果上盖楼。

2020 年前后，风向变了。领先的公司发现价值可以独占，不透明回归。Mensch 说，软件行业早就见过这种开放与封闭的循环，现在轮到 AI 再走一遍。

他的反对理由很具体：这项技术远没做完。推理不行，记忆机制没搞懂，因果机制没搞懂，可控性差，偏见一堆。还需要发明新技术，而发明新技术的前提是有人能大规模试错。现在有钱试错的那几家公司，拒绝交流了。结果就是几家巨头在互不沟通的情况下，花几十亿的算力做同一件事。

「我们的意图是占据这个位置，改变游戏规则，因为我们认为现状没有把领域带向正确的方向。」

Sarah Guo 补了一刀：如今大科技公司嘴上说开源 AI 危险，实际效果像监管俘获，用监管锁死创新，顺便锁死行业控制权。放眼全球健康、全球公平这些议题，开源恰恰是全人类透明受益于这项技术的最大通道。Mensch 补充，社区一直在等开源玩家出现，Meta 转向开源让他很感激。

生化武器叙事是怎么被造出来的

安全争论是这期节目信息量最大的部分，Mensch 刚在布莱切利园的 AI 安全峰会上辩过一轮。他的立场很务实：今天开源一个模型，到底给了坏人多少边际能力？他的结论是零。

他把论证拆成两个前提。要证明开源大语言模型不安全，得同时证明两件事：第一，它在获取危险知识上比搜索引擎有边际优势；第二，知识是滥用行为的真正瓶颈。两个前提都不成立。大语言模型压缩的是互联网上本来就公开的知识，边际上没有制造任何新的危险。

那生化武器的恐慌从哪来的？Mensch 溯源到 GPT-4 技术报告的附录，大约第 46 页。模型生成了某种化合物，报告顺笔提了一句，不希望模型去推理化合物，但那个化合物本身并不危险。这本来是预期内的观察：用生物学文章训练的模型，当然能产出化合物。接下来发生的事才是重点：没有任何正式的科学研究发表，政策论文开始引用非科学材料，然后政策论文互相引用，最后决策者读到的是几十篇论文齐声说生化武器要出事。

Elad 问，为什么偏偏是生化武器？他做了近十年生物学家，知道造一个病毒有多复杂。Mensch 承认自己也没有完整答案，只给了两个观察：一是模仿效应，一篇论文的注脚滚成一场运动；二是 COVID 的集体创伤，他说那场疫情夺走了 3000 万人，没人想再来一次，但下一场大流行更可能来自气候变化，而非一个 token 生成器。

行政令划的算力红线，他同样不买账。10 的 26 次方 FLOPs 这条线，高到 Mistral 未来几年都够不着，但完全任意：谁证明过超过这个数就会出现危险能力？能力和规模的关系本来就粗糙，真正起作用的是数据，行政令后来确实给生物数据单独设了预算，等于承认了这一点。该度量的是能力，该谈清楚的是哪些能力算危险，而不是拿算力门槛当市场准入。

护栏装在模型上，还是应用上

Elad 把安全讨论拆成三层：内容风险，仇恨、违法、偏见；物理风险，生化武器、基础设施破坏；生存风险，AGI、新生命形态、资源竞争。Mensch 认为必须分开谈，因为三层的证据状况完全不同。第一层有成熟方案；第二层目前没有证据，近期也看不到；第三层是哲学问题，能造任意复杂的系统，它就能做任何事，可我们离那一步还很远。

他补了一个机器学习视角的冷判断：复杂性带来的往往是无所作为，因为缺少自组织和意志。机器学习里的「崩溃」指的是掉进局部极小值后彻底停摆，复杂性必然导致崩溃这件事并没有依据。

「作为科学家，我只信我能看见的东西。」

落到产品上，Mensch 的方案是模块化护栏。模型会输出任何文本，应用需要过滤输入和输出。做法是提供未经改动的原始模型，在上面叠加过滤器模块，检测色情、仇恨言论这类输出。聊天机器人要禁这些，但拿模型做内容审核的应用，反而需要模型懂这些。

「模型应该表现良好」是个错误假设，正确假设是模型应该什么都知道，然后在上面加审核模块。Mistral 把做好这些模块当成平台责任，并且主张靠竞争而非自觉：监管要求应用开发者合规，比如聊天机器人不得输出仇恨言论，开发者就会去市场上找最好的护栏方案，这个赛道自然有经济动力。指望几家巨头自己管自己的安全，机制上就走不通。

Agent 的账本，和巴黎的飞轮

Agent 是当下的热词，Mensch 给它泼了两瓢冷水，也指了一条明路。第一瓢：跑在 GPT-4 上的 Agent 烧钱太快，把算力成本除以 100，能建的东西立刻不一样，所以做小模型本身就是给 Agent 铺路。第二瓢：现在的 Agent 普遍出现模式坍缩，开始重复自己、掉进死循环，这里有硬研究要做，包括让模型更会推理，让模型学会按任务难度自适应分配算力。

平台是 Mistral 的另一半生意。训练侧要做省内存的架构，Mistral 7B 的稀疏注意力就是干这个的。推理侧要写高效代码。API 走时间共享路线，一台 H100 能同时服务几百个客户，实验期的需求大到惊人。企业客户可以自托管。两条腿走路。

至于为什么把公司留在法国，Mensch 的答案带着法国人的骄傲：法国、英国、波兰最擅长培养数学家，而数学家做 AI 有天然优势，这批人里很多想留在欧洲，家人在，饭也更好吃。伦敦的生态靠 DeepMind 起家，巴黎靠 DeepMind 和 Meta 设立的实验室，加上回流的创业者。巴黎现在有几百家 AI 初创公司，投资人、运营者都在进场。比不了硅谷，但旧金山那种飞轮，在法国开始转了。

明天就能用的四件事

  • 选模型先算推理账。把训练成本和推理成本分开列，高频调用、多轮循环的 Agent 场景，7B 级别的小模型大概率比旗舰模型划算，先在本地 MacBook 上跑通原型，再考虑上云。
  • 护栏做在应用层。用开源模型时，保留原始模型的完整能力，在输入和输出两端加过滤模块，规则按应用场景定。别指望模型天生干净，也别把模型阉割到没法干活。
  • 盯住蒸馏和合成数据。大模型发布之后，小模型会跟进变强，为参数量付溢价之前，等一等同代的蒸馏版本。
  • 评估 Agent 项目先测两件事：单位任务的成本，和长循环里的重复率。前者决定能不能规模化，后者决定靠不靠谱。

节目上线一个月后，Mixtral 8x7B 发布，混合专家路线把「大模型反哺小模型」的判断又兑现了一格。这场开放与封闭的轮回，下半场才刚开始。
