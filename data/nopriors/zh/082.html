《API 价格两年降 200 倍，LLM 市场的牌桌却还没坐定》

2024 年 9 月，No Priors 出了一期没有嘉宾的节目，两位主持人自己对聊。Sarah Guo 是 Conviction 的创始人，Elad Gil 是硅谷知名的连续创业者和投资人，这期聊的问题很扎心：LLM 这个市场，是不是已经洗完了。

先看 Sarah 团队拉出来的一张表。他们把各家模型的 API 定价按时间排了一遍，结论是过去 18 到 24 个月，调用成本降了大约 200 倍，每百万 token 的美元价格跌得非常夸张。

按常理，价格卷成这样，市场该收敛了。Elad 给出的却是另一个方向的事实：头部模型公司新一轮融资的单位已经是十亿甚至几百亿美元，出钱的只剩超大规模云厂商和主权基金，传统 VC 的资金池根本接不住这个体量。

一边是价格崩到地板，一边是融资涨上天。整期节目聊的就是这个拧巴的局面：牌桌坐定了没有，创业公司还有没有活路，芯片和内容两条战线又该怎么打。两位主持人的判断也不完全一致，Sarah 强调竞争在加剧，Elad 强调整合在加速，两边的证据都值得看。

牌桌上的钱，只剩云厂商和主权基金出得起了

Elad 先摆洗牌的证据。一批明星模型公司的核心团队并进了大厂：Inflection 的一部分人去了微软，Character.AI 的创始团队回了谷歌，Adept 的团队进了 AWS。公司有些还活着，产品还在跑，但牌桌上的独立玩家实质上少了一批。

更硬的门槛是钱。模型能力的每一次跃升，背后都是越来越贵的训练账单，能开出这种支票的玩家屈指可数。云厂商愿意掏钱也好懂：模型跑得越多，云的消耗越大，投资直接转成自家云的用量。Elad 补了一句，VC、云厂商、战略投资方、主权基金这几方的激励正在互相翻转，谁想要什么，隔几个月就变一次。

他还给了一个可以动手画出来的思考题：把苹果、三星这些还没绑定模型的大厂列出来，再把这些格子跟各家模型公司连线，谁跟谁配对，行业格局的轮廓大概就出来了。

Sarah 同意整合在发生，但她补了一个关键观察：过去一年半，这个市场的竞争变得更激烈，强度在上升。benchmark 上性能你追我赶，价格一路下探，开源模型还是真刀真枪的对手。于是出现一个少见的状态：行业在整合，同时大家还没赚到钱，两件事完全能同时成立。

降价 200 倍，只卖 API 的生意越来越难

200 倍的降价从哪来？Sarah 团队里一位叫 David 的同事把各家定价排成图表，她拆了两块原因：一部分是蒸馏，大模型教出小模型；一部分是硬件换代，新 GPU 把推理成本打了下来。用量在涨，能赚到的钱也在涨，但单纯卖模型 API 这个生意，越来越难做了。价格崩得比用量涨得快，你被推着往特化方向走：定制模型、专项后训练、垂直应用。

Elad 说了句大实话，头部公司敢融这么多钱，那个没明说的商业计划，说到底还是 AGI 本身。

模型会涌现出能力和行为，它会自己想出怎么赚钱，或者它的价值会明显到不需要解释。

他没说这个逻辑错，只提醒在两三年的现实周期里，看得见的生意就两块：to C，订阅或者广告，广告这条路还没人真刀真枪走过；to B，企业服务。这两块今天都是真的。

竞争也已经从研究卷到了产品。Sarah 点了两个人事任命：Instagram 联合创始人 Mike Krieger 去了 Anthropic 当首席产品官，Kevin Weil 出任 OpenAI 的首席产品官。大厂开始围绕资本护城河和研究积累，往上再垒一层产品护城河，聊天界面之外做出更多东西。

另一条战线是锁定。Sarah 拿 AWS 的老剧本打比方：别以为这只是一个存储桶，prompt 缓存、JSON 输出接口、微调，功能一层层加上去，用户用顺手了就懒得换了。Anthropic 的 prompt 缓存就是一步好棋，成本和延迟两头都占。一旦用户把这些功能用起来，模型市场就没那么大宗商品化了。

这条路的终点，是模型本身越来越像大宗商品，差异化的主战场挪到了功能和接口上。Sarah 自己作为消费者挺期待界面层的进化：聊天不会消失，但会出现带自动上下文、跑在不同入口上的更聪明的聊天。

那后来者还有没有路？Sarah 列了几条：推理路线上的差异化，比如有人押注用数学和代码做自我对弈；追赶上来的成本在降，别人趟过的路你不用重趟，硬件进步还在白送红利；蒸馏和小模型微调能走到哪一步，也是开放问题。

Elad 补了一个范围澄清：这场讨论只针对语言模型。物理、生物、材料科学、图像生成，各有各的模型市场。而且行业在三根轴上同时进化：模型本体是一根，推理和 agent 流几乎是正交的另一根，模型周边的基础设施是第三根，长上下文、RAG、缓存都算这一层。

社交网络的历史：宣布终局的人总被打脸

市场会不会真的收敛到只剩几家？Elad 拿社交网络的历史打了个比方。当年所有人都觉得 Friendster 会赢，后来觉得 MySpace 会赢，等 Facebook 冒出来，大家又说社交已经是大宗商品市场，不可能再有长期差异化。结果 Facebook 赢下了核心社交，之后 Instagram、Twitter、Snapchat，再到字节和 TikTok，一波接一波。LinkedIn 占了职场身份，Twitter 占了实时信息。每一波都有人宣布社交已死，每一波都冒出新巨头。每次有人宣布某个市场结束了，下一波玩家都已经在路上。

视频和音频会不会走同样的路？Sarah 的判断是：大概率一部分走通用模型，一部分走特化模型。关键看两件事，模型能力本身能泛化到什么程度，围绕模型的工具链要不要跟模型垂直绑死。同一个图像生成产品，可能同时服务艺术创作、平面设计和 UI 设计，这到底是一个模型加微调，还是好几个特化模型，现在没人说得准。工具链绑不绑死的问题，在语音上同样成立。

她还引了大脑做参照。大脑是一组相当特化的模块，视觉、情绪各管一摊。心理学文献里那个著名的盖奇案例，一根铁棍意外穿过头颅，当事人只丢了某一类情绪和推理功能，其他一切照旧。模型最终特化到什么程度、通用到什么程度，是个开放问题。

图像生成市场最近几个月明显热起来了。此前大家默认 Midjourney 会是那个独立赢家，OpenAI 有 DALL-E，谷歌有 Gemini 侧的东西，现在一批新公司的保真度都起来了。Sarah 顺带自嘲了一下，她一直判断视频、图像、音频模型会快速变强然后大宗商品化，每次还是会被速度惊到。Sora 发布时大家都在问谁能追上，现在 Runway 和 Pika 已经咬得很紧，Ideogram、Hotshot 这样的中小团队，还有 Luma AI，都拿出了能打的东西。

五个人、没多少钱的团队，几个月前还被叙事判定为不可能，现在能做出有竞争力的模型。她说这是她认知上一次实打实的更新。

Elad 补了另一个没多少人预料到的趋势：模型在变小，性能在变强。靠蒸馏也靠别的手段，同样的性能，参数规模一路下探，两年前行业刚起势的时候，很少有人押这一手。你早知道有压缩空间，但能压到这个程度，还是超出了预期。参照系还是大脑：一个 20 到 30 瓦的设备跑在你脑袋里，通用视觉识别样样行，压缩的余地还大得很。

Sarah 接着说到实时应用：模型更小更快，加上 Cartesia 这类新架构，语音和图像可以边说边生成。今天生产环境里跑的实时应用几乎没有，边说话边出图和干等一张图渲染完，是完全不同的体验。她的预期是这类东西接下来几个月就会来。

Google 的十年官司，Napster 的坟，和 Grok 的实验

Elad 花了很长一段讲 Google 的老故事。早期的 Google 把全网内容索引了一遍，靠别人写的东西赚钱，新闻界和版权方轮番起诉它。争议焦点是搜索结果里链接上方那一小段文字，有人主张这段摘要受版权保护，够不上合理使用。

这场拉锯战打了十年到十五年，最后落成四件事：robots.txt 出现了，网站从此可以自己声明要不要被抓取；摘要被判定属于合理使用；财经、体育这类特殊内容签了一批授权协议，接进搜索页顶部的直达答案框；最讽刺的是第四件，退出 Google 索引的新闻网站发现流量暴跌，又主动回去求收录，因为不在 Google 里的损失，比在 Google 里更大。Google 靠一支专盯版权的强法务团队，把这条钢丝走完了，几乎毫发无伤。

Sarah 补了另一组先例：Airbnb 和 Uber。它们正面冲撞了短租管制和出租车牌照，这套旧规则在当时被很多人视为监管俘获。如果它们等规则改完再动手，这些服务根本不会存在。打法是先赌消费者要这个东西，冲到规模，边跑边摸清风险，等有了市场地位再谈政策。她的判断是，很多 AI 公司都会在路上反复撞见这些问题。

落到今天，一个高频问题是：抓 YouTube 数据训练视频模型，Google 会不会找上门。

如果真有办法在完全不碰 YouTube 数据的前提下，把视频数据的规模做上去，我会非常震惊。

她还反问了一句：Google 自己默许各种抓取搜索结果的生意存在，那它对 YouTube 数据的态度，在法律上跟自己的核心业务是不是有点双标。

Elad 提醒硬币的另一面：Napster。音乐工业把它直接告进了坟墓，因为侵权太赤裸。所以风险要拆开看，他分了三类：法律和诉讼风险，两者还不总是一回事；监管风险，监管框架不清晰的加密货币是典型，今天的 AI 里也有类似灰色地带；声誉风险，即你允许模型输出什么。

第三类里他点名 Grok。xAI 明说不会像别家那样严管输出，文本和图像都放得开。这某种程度上更接近真实人类社会的表达常态，而很多公司把模型管得比社会主流规范还紧，有些限制是为了用户好，有些明显是政治驱动。社会到底在多大程度上在意模型输出符合既有的表达规范，这是一场正在进行的大实验。

Sarah 补了一个哲学切分：管生成，还是管分发。拥有平台的人管分发是责任，生成则更像言论自由的范畴。这道题没有现成答案。

芯片牌桌：AMD 攒拼图，新玩家押 transformer

Sarah 把话头引到半导体，她的开场逻辑很简单：训练和推理都压在半导体性能上，这层值得单独聊。芯片创业出现了新一批公司，上一波是六七年前的 Groq 和 Cerebras，这一波有 MatX、Etched，节目后面几期会请到其中几家。

Elad 先致敬了上一波的远见：他们判断 AI 负载需要不一样的计算，这个判断是对的。他真心佩服这种前瞻，只是把宝押在这么远的未来，实在太难。芯片和系统设计一旦开弓就没有回头路，一个架构赌注要押很多年，七年前没人能确定规模化的 transformer 会吃下这么多负载，市场演化得非常不可预测。现在这批新公司高度聚焦，围绕 transformer 架构和矩阵运算的面积分配做优化。

能不能跑赢 AMD 和英伟达的价格性能曲线，是绕不开的问题。这两家到今天都是高速创新者，AMD 也在明显进步。芯片投资的本质就三件事：你愿意押什么架构赌注，交付节奏能不能跟上，价格性能打不打得过。两人都觉得这个注值得下。需求端还冒出了主权云这个新形态，各国自建 AI 基础设施，给新公司留了订单窗口。

AMD 收购 ZT Systems 这步棋，两人拆了一下。市场对 AMD 能不能追上英伟达分歧很大，Elad 把 AMD 需要的拼图列了出来。软件层，对标 CUDA，所以先买了 Silo AI，约 6 亿美元，本质是一笔收购式招聘，拿下几百个在 AMD 平台上做过大量工作的 AI 工程师和研究者。网络层，AMD 在推 UALink，开源阵营对标 NVLink 的方案。最后是 ZT Systems 补上的那块，按 Elad 的算法，这相当于花 10 到 20 亿美元收购式招聘了约一千名系统设计工程师，把生意从单颗芯片和部件升级到机架和数据中心级。因为英伟达真正在卖的东西，已经是整套数据中心，靠多年战略把整套系统卖给研究实验室。拼图看起来都在了，能不能拼起来是另一回事。

明天就能用的四件事

聊的全是行业格局，拆下来有几条明天就能上手。

  • 用 200 倍降价曲线重算一遍你的产品账。18 到 24 个月前算不过来的成本，今天可能全通了。还在用去年的 API 价格做预算和定价的，先把表改了。
  • 只包一层 API 转卖的生意最危险。价格崩了，这层护城河跟着崩。往三个方向加厚：垂直数据、专项后训练、让用户用上缓存和微调这类有迁移成本的功能。
  • 动手抓数据或者放开输出之前，把风险拆成三栏打分：诉讼、监管、声誉。Google 穿过钢丝靠的是强法务加十年耐心，Napster 的坟就在隔壁。先想清楚自己赌的是哪一类。
  • 别急着宣布终局。社交网络被宣判了三次死刑，又活了三次。LLM 牌桌远没坐定，五人团队做出竞争力模型的事刚刚发生过，观察窗口还开着。

节目结尾有个小彩蛋，Elad 现场发了一条求购启事：想收一台人形机器人，或者波士顿动力的 Spot，有渠道的欢迎联系他。牌桌上的大问题还没答案，先买个机器人回家，也算是一种行动派。
