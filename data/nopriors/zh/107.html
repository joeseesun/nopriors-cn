《Copilot 已经写下一半代码，GitHub CEO 却说智能体上岗还差四道关》

2021 年，Copilot 预览版上线不久，GitHub 内部产品评审会上出现了一个数字：AI 写了 25% 的代码。CEO 托马斯·多姆克当场说，这肯定是遥测出了错，让人回去重新验证。数字没错，那只是个还会频繁犯错的自动补全。

今天这个比例涨到 50% 左右，随编程语言浮动。而在几天前发布的 agent 模式里，用户只敲一句提示词，比如「用 Python 写个贪吃蛇」，AI 直接生成多个文件的完整代码。多姆克的原话是，分母归零了，百分比失去意义。两年前要演示 15 分钟的东西，现在 1 分钟讲完。

多姆克执掌的 GitHub 有超过 1.5 亿开发者。他成长于东柏林，柏林墙倒塌后买了人生第一台电脑 Commodore 64，十年前微软收购他创办的公司，他搬去了美国。GitHub 今年满 18 岁，微软 4 月 4 日满 50 岁，这家子公司现在是微软在 AI 上最激进的前线。3 月 13 日的 No Priors 播客里，他和投资人 Sarah Guo、Elad Gil 聊了一个小时：当 AI 接管写代码，软件行业会变成什么样。

从副驾驶到同事：Padawan 计划

先说已经上线的。Copilot 的 agent 模式进了 VS Code，它开始帮你实现完整功能：需要装依赖包时，它把终端命令摆出来，你点头它才执行。人始终在环上，这是当下所有智能体的共同前提。

重头戏是 2025 年的 Padawan 计划，名字取自绝地武士的学徒，多姆克提醒大家，当学徒要有耐心，还得学会使用原力。设想是这样：你把一个定义清楚的 GitHub issue 指派给 Copilot，它自己起草 pull request，列出计划，然后逐条执行，像同事一样往 PR 里提交代码。你可以像观察同事干活那样看着它提交，随时回滚某个 commit，在 VS Code 里检出细节，最后给评审意见。

Copilot 基本上会从结对程序员毕业，成为同行程序员，成为你团队的一名成员。

离这一步还有多远？多姆克给了两个变量。第一个是模型，OpenAI 完整版 O3 还没放开，推理能力上去了，SWE-bench 的成绩才会继续爬。这个基准由普林斯顿的一个团队搭建，从 12 个开源 Python 仓库里整理出约 2200 组 issue 和 pull request 配对，现在所有模型和智能体都在上面比武。

第二个变量比模型更具体。智能体要被广泛采用，得过四道关：可预测、可引导、可验证、可容忍。可预测，是你看一眼 issue 就知道这活它能不能接；可引导，是它接不了的时候会回来追问，或者由你补充定义；可验证，是产出躺在 PR 里，commit 一目了然；可容忍，是它别浪费你的时间。最大的未知其实是交互流程：拿到一个 issue，开发者怎么判断该派给智能体，还是该先把需求写得更细，这套判断标准行业还在摸索。

最后一条最扎心。多姆克观察到，开发者一旦看到智能体反复空转、白烧算力，第二次就不会再打开它。信任建立得很慢，摧毁只要一次卡死。

他也揭了揭自家的开发流程。行业现在管这个叫 AI 工程：应用科学团队跑评测，另一个团队专门搭基准，做代码评审智能体和 agent 模式的工程师拿这些基准验证自己的活。离线测完，先在 GitHub 和微软员工身上灰度，再放给一部分用户做 A/B 测试。数据科学家和工程师的岗位边界，在 GitHub 内部先模糊了。

一半代码是兴奋剂，另一半是清醒剂

这场对谈有意思的地方，是多姆克同时端出了乐观和泼冷水的数据。

乐观的：GitHub 给 Padawan 录演示时，让一位平时不写代码的产品经理直接派活。PM 写了个 issue，智能体生成了 pull request，工程师评审后合并进代码库。一个不碰代码的人，交付了一段真正上线的功能。

泼冷水的：智能体会卡死。它会反复重写同一个文件，或者干脆把整个文件删掉，因为它陷在自己的逻辑里出不来。多姆克的判断是，离「智能体自动扫完我所有 issue、清空积压」还很远，你现在能扮演的角色，是给开发智能体当人类评审员。

那中位数程序员会被替代吗？他的答案很明确：系统思考能力保住了中位数开发者。你脑子里有个大想法，能在白板上画出来，但要拆成一个个可执行的小任务，中间全是决策：用什么数据库、上哪家云。你跟智能体说「帮我造一个 GitHub」，它只会一脸茫然，这句话太不具体了。反过来的那部分工作，修 bug、接 issue、在陌生代码库里找到该改哪几个文件，他判断这一年会有戏剧性进展。

代码评审、安全债和正在溶解的岗位边界

写代码只占开发者每天两三个小时，剩下的大头另有战场。开发者花在评审同事代码上的时间，跟写代码差不多。多姆克认为人工评审不会消失，出于安全和信任，代码合并进生产环境前总要有另一双人类的眼睛。但第一轮初审可以交给智能体，尤其跨时区团队，不必等西海岸的同事睡醒才拿到反馈。

配套基建也得跟上。如果每次处理评审意见都要本地克隆仓库、装依赖、切分支，样板工作一点没省。他的方案是把流程搬进云端环境，打开就能改，外循环才快得起来。

更实际的收益在安全债。代码扫描不该只报漏洞，还该顺手修掉；linter 那一百条「括号后面加空格」的警告，应该全部由 AI 消化。任何像样的软件项目都背着一堆已知漏洞，多数低危，或者代码根本走不到那条路径，就一直拖着。让 AI 清这笔积压，等于把工程经理从救火队长的位置上解放出来。他的日常就是在技术债、遗留代码、安全、无障碍、欧盟合规和创新需求之间来回摇摆，哪边火大扑哪边。

岗位边界也在溶解。Copilot Workspace 里已经有个规格与头脑风暴智能体，读你的 issue，对照代码库，用人类语言写出改动前后的说明，你可以像改 Notion 文档一样改这份规格。多姆克预判，产品经理写好规格就能生成完整变更集，设计师输入同样的规格、套上设计系统，就能渲染出线框图对应的代码。描述问题的能力，正在成为产品、设计、工程三个工种共同的核心技能。十人创业公司没这个烦恼，创始人就是产品经理；一千个工程师的公司，最大的难题从来都是「到底要造什么」。

定价：智能体不会按程序员的工资收费

商业数据，多姆克给的是几个季度前的数字：7.7 万家组织在用 Copilot，付费用户 180 万，最新数字不能说。但他算了一笔账：Copilot 每月 20 美元，约占美国程序员平均工资的 0.1%，换来的端到端生产力提升约 25%，纯编码任务超过 55%。这大概是软件史上投入产出比最悬殊的一笔采购，也是采纳速度横跨所有行业、所有公司规模的原因。

为什么大家愿意买单？他引了《星际迷航》的老段子：柯克船长问斯科蒂修曲速引擎要多久，工程师报一个长得离谱的时间，然后船长拍板期限，谈判代替了估算。所有写软件的组织都被「为什么这么慢」折磨着。多姆克说得很直白，Copilot 的生意就建立在这种挫败感上。

未来怎么定价？他的判断：按算力，或者算力的某种衍生单位。买家不会为一台机器支付程序员的工资，就像没人给洗碗机按人工洗碗的费用定价。人类程序员贵，因为供给有限；智能体供给无限，唯一的约束是数据中心的 GPU。方向是变便宜，但会分层，OpenAI 的深度研究档位每月 200 美元，两年前没人相信有人为聊天机器人付这个价。另一头，用户为一个 5 美元的手机订阅骂翻天，觉得软件就该像 CD 一样一次买断。多姆克的结论是，涨价会跟着价值走。

这个话题引出了两段往事。多姆克先说，稀缺性今天还活在超跑市场，保时捷 911 RS3 的二手价比新车高，你得先在经销商那儿买够 100 台保时捷，才轮得到那一台顶配。然后是他父亲那辆特拉贝特，1984 或 1985 年卖给邻居，卖价比当年买价还高，因为排队买车要等 17 年，很多父母在孩子出生时就去登记名额。稀缺性消失之前，价格逻辑一直都在。

还有一个反差数据：Copilot 每月 20 美元，GitHub Enterprise 是 21 美元。一个自动补全功能，卖得比整个软件研发平台还贵。五年前谁信。所以多姆克认为软件价格会通缩，同时你会为 Netflix 和 Office 订阅付比以往更多的钱，两件事同时成立，核心只看你的业务从中拿到多少价值。

没有赢家，只有无限游戏

Copilot 现在内置 Claude、Gemini 和 OpenAI 的多个模型，GitHub Models 目录里还有 Llama、Mistral、Cohere 和微软的 Phi-4。为什么不绑死一家？多姆克反问：如果 GitHub 上只有 React 一个库可用，会怎样？用户会跑光。开发者选择权是刻在 GitHub 信仰里的东西，不同场景本来就有不同的最优模型。

Sarah 问，模型会不会最终趋同，选哪家都行？多姆克拿历史作答：Copilot 项目 2020 年 6 月启动，用的是 GPT-3，后来专门训练了代码模型 Codex，今天 Codex 作为独立模型已经不存在，所有人都盖在更强的基座模型上，通用性吃掉了专用性。但他紧接着补了一句，他开了十年带自动辅助驾驶的特斯拉，到现在还没法自动拐进他家小区那个左转口。看得到那个未来，猜不到具体哪天到。

开源在这场竞赛里是加速器。DeepSeek 年初那一波，论文公开、模型开放，有的用 MIT 协议完全开源，有的是开放权重但受中国法律管辖。再加上图像领域的 Stable Diffusion 和黑森林实验室的 Flux，开源和闭源你来我往，整个行业被共同推着跑。对学生和研究者来说，不用调商业 API，本地就能跑模型，门槛塌了。

那谁会赢，iPhone 还是 Android，Windows 还是 Linux？多姆克的答案是没有赢。技术行业的二元对决叙事从来没成真过，React 之前是 jQuery，Python 和 TypeScript 之后还会有新语言，Rust 五年前根本不算个东西。软件像 Minecraft，你能赢下小战役，但这个世界只会越建越大，永远有下一个大东西。

竞争本身他倒欢迎。这位写了 30 年代码的 CEO 说，这是开发者工具史上最兴奋的时刻，一年前 SWE agent 连个概念都算不上，现在市场上已经挤满试验者。F1 车迷都懂，能争冠的车队越多，比赛越好看。GitHub 的应对方式是把自家用到极致：用 GitHub 造 GitHub、在 GitHub 上造 GitHub，法务条款、HR 政策、产品管理全都活在 GitHub 的 issue 和仓库里，他每天早上睁眼第一件事是打开手机上的 GitHub 应用，第二件才是 Slack。市场快到什么程度？无论是和 OpenAI、Anthropic 还是 Google 开会，得知新模型版本后，路线图一夜之间就得改。多姆克说，整个行业坐在一条指数曲线上，没人能做超过一两个月的计划。

Elad 追问了一个更远的问题：会不会有一天，所有人都不再从应用商店装软件，改用自然语言现场生成自己的应用？多姆克说这就是钢铁侠的贾维斯，完全个人化的界面，五年内一定发生，问题只是好不好用。他对着智能体说「年度旅行还是老地方、老行程，直接订好」，唯一留给他的问题是：要不要升商务舱。

回不去的东柏林，和三件明天就能做的事

Elad 提了一个资深工程师圈流传的担忧：新一代人靠 AI 写代码，会不会长不出架构品味，理解不了边界情况怎么失败？多姆克说这个担忧有几分道理，用 AI 在编程练习里作弊太容易了，未来的黑客马拉松和 Advent of Code 只能默认选手带着 AI 参赛。

但他自己的成长经历给出了另一个视角。东柏林没有互联网，他靠买书和杂志学编程，每周三去计算机俱乐部，直到俱乐部里没人能教他新东西。今天的孩子面对的是无限的知识，和无限的耐心。Copilot 不会耗尽耐心，父母会。父母不需要任何技术背景，一部手机加网络，孩子就能把布尔逻辑问到无限深。他管这叫智能体的交响乐团，而新一代天生就是指挥。他手下工程师说得最多的话，是活太多、时间不够、快被烧干了，缺的从来都是时间。

节目的结尾回到 1989 年 11 月的那个星期四晚上，广播说柏林墙开了。周五照常上学，周六上半天课，全班只来了四个孩子，然后被遣回家，他们穿过关卡去了西柏林。多姆克说，经历过那种剧变的一代人，童年故居、街角商店、整个体系都没了，回不去了。互联网之前与之后，开源之前与之后，云、移动、AI，他的人生被切成一段一段。这一次，他同样不打算回头看。原话里留了个出口：你依然可以把手机扔到墙角，过没有互联网的一天。AI 会渗透进几乎所有事，前提是你想要。

最后，把这场对谈压缩成三件明天就能上手的事：

  • 把 issue 写到智能体能接手的程度：背景、边界、验收标准一次写清。描述问题正在取代写代码，成为软件团队最稀缺的能力。
  • 用四条标准检验你手上的 AI 工具：可预测、可引导、可验证、可容忍。任何一条不达标就趁早换，空转的工具烧的是你的时间和信任。
  • 把重复劳动先交出去：linter 警告、低危安全积压、跨时区评审的第一轮意见，这些是智能体今天就能干的活。省下来的时间，留给数据库选型、系统拆分这类机器替你做不了的决定。
