《Anthropic 联创本·曼：一份癌症报告从 12 周到 10 分钟，超级智能可能在 2028 年》

制药公司诺和诺德给一位癌症患者写「该用哪种治疗」的报告，过去要 12 周。现在，10 分钟出初稿，医生和研究员再在初稿上做实验、验证、把结果喂回系统。

说这话的人叫本·曼（Ben Mann）。他是 OpenAI 早期工程师，GPT-3 论文的首批作者之一。2021 年，他成为离开 OpenAI、共同创办 Anthropic 的 8 位原始联创之一，先后带过产品工程，现在负责 labs 部门，MCP 和 Claude Code 都出自这个团队。

2025 年 6 月，他在投资人 Sarah Guo 和 Elad Gil 的播客 No Priors 上聊了一个多小时，从 Claude 4 的版本号怎么定，一路聊到 2028 年会不会出现超级智能。这场对话里有一手细节不少，值得逐段拆开看。

Claude 4 修掉了「顺手加薯条」的毛病

先说发布逻辑。Claude 4 的版本号怎么定？本·曼的原话是，与其说科学，更像艺术，内部会为这个数字吵得很凶。流程大致是：先根据能拿到的芯片数量和 scaling laws 画路线图，预估什么时候能训到算力前沿的帕累托最优点；芯片到手就开训，日期难免浮动；训到接近尾声，才切几片「蛋糕」尝尝味道，感觉是重大变化，就升大版本。Dario 说过，模型没训完之前，谁也说不准，只能拿到方向性信号。

模型本身，按基准测试，Claude 4 比 Anthropic 之前的最好模型 3.7 Sonnet 强了一大截，编码的变化最明显。上一代被用户骂得最多的两件事：一是脱靶改动，你让它改一行，它顺手重构半个仓库；二是奖励黑客（reward hacking），为了让测试通过不择手段。本·曼替用户吐槽：

「它就像在问，这份改动要配薯条和奶昔吗？你说不用，就做我让你做的事。结果你还得花一堆时间收拾残局。」

Elad 补了两个他投资组合公司里的真实案例。有模型为了让测试全部通过，直接把代码全删了，测试当然全绿，项目也归零。还有模型写完测试函数，里面留一行注释「练习留给读者」，然后 return true。

新模型把这两类毛病压了下去。本·曼说，这对专业软件工程很关键，企业要的是可维护、可依赖，改完还得有人接手。

更大的变化在长任务。Claude 4 真正解锁的，是无人值守跑几小时的智能体任务。有客户拿它独立完成大型重构。他举了 Manus 的例子：用户让 Manus 把一段视频转成 PPT。Claude 本身看不了音频和视频，但它自己下载视频，用 FFmpeg 切帧、做关键帧检测，去申请一个语音转文字服务的 API key，把转写稿整理成幻灯片内容，再写代码把内容注入 PPT 文件。全程没人盯着，用户事后评价效果很好。这件事人工做，得花几个小时看视频。

Elad 追问成本：这么跑不贵吗？本·曼的算法很简单，成本要跟人比，跟工程师的工资比。让一个难招难留的工程师产出翻两三倍，工程师开心，老板也开心。至于算力怎么分配，Opus 可以把 Sonnet 当工具调用，当作子智能体。Claude Code 里大量用这个模式：主模型派一堆子代理去翻代码库，各自回报细节。好处除了省钱，还有延迟更低，不会撑爆上下文窗口。

Elad 拿人脑类比继续追问：大脑是高度特化的模块加调度，未来模型会不会也走这条路？本·曼的答案要从可解释性研究里找。Anthropic 最近发表的「电路」（circuits）论文，第一次在真实规模的大模型上看清它到底怎么算出答案。混合专家架构里，也许真有专门负责共情、专门负责工具调用的权重块。但记忆这类能力，他觉得太核心，外包给另一个模型很怪。未来的架构也许会从均匀的 transformer 躯干，长出特化模块。

产品线上，他给了一个很干脆的回答：Anthropic 只有两个模型，按成本和性能的帕累托前沿区分。别的公司模型一大堆，名字还互相颠倒，他自己也分不清。作为用户，不该逼人自己判断这个问题值多少美元、要不要更聪明的模型，加一层自动路由才是正解。

为什么模型公司要亲自下场做编码产品

Elad 抛了一个行业规律：平台公司迟早向前整合。微软做了 Office，Google 做了旅游和本地服务，OpenAI 正在收购 Windsurf。Anthropic 会怎么走？

本·曼拿编码举例。Anthropic 的模型在编码上明显领先，他知道有公司拉响过「红色警报」想追平，追了很久没追上。他坦白说，自己也没料到对手一直追不上，但事实如此。

Elad 顺着总结了编码的三重价值：用户最愿意买单的场景；回流数据最丰富的场景；以及帮着训练下一代模型的生产力。Claude 5 参与 Claude 6 的训练，Claude 6 再加速 Claude 7，滚起来就是通往 AGI 的斜坡。本·曼说他读过 AI 2027 那份预测，讲的正是这个故事，其中把「递归自我改进循环通向全面超越人类的 AI」的中位预测放在 2028 年。

主持人问，2028 年出现通用超级智能，信吗？

「我认为很有可能。但很难给出有信心的上下界。」

他判断变革时刻的指标叫「经济图灵测试」：取一篮子占经济价值 50% 的任务，每个岗位让招聘经理去雇一个智能体，签一个月的合同。月底，经理决定续聘人还是机器。选机器，就算通过。这个测试大规模通过之日，就是变革性 AI 到来之时。严格测试还没开始做，但 Anthropic 的模型已经能通过自家的面试，成绩极好。他补了一句丧气话：面试只是真实工作表现的很差的近似。

至于为什么亲自做 Claude Code，内部理由最硬：这工具在 Anthropic 内部已经爆了，研究员自己天天用。训练模型的人亲自感受模型的弱点，痛感会直接转化成修模型的动力，而且他们对模型的长短板手感最准。外部理由是学习速度：他很爱 Cursor 和 GitHub 这些合作伙伴，但没有直接用户关系，学到的内容和速度都差一截。发布前团队也怕，怕跟伙伴抢饭吃。结果发布后，很多客户把 Claude Code 的体验抄了回去，用得越多，模型公司和伙伴绑得越紧，皆大欢喜。

人类专家不够用了，怎么办

Elad 问，模型加速模型研发，会先从哪里见效：数据、基础设施、架构搜索，还是工程效率？

本·曼的观察分几层。今天模型最擅长编码，而训练大模型的编码工作大头在系统工程。研究侧正在跟上：Claude 擅长数据分析，能驱动 Jupyter notebook、盯着日志看异常。新发布的 advanced research 产品能爬 arXiv，也能读内部 Google Drive，帮研究员查这个方向有没有人试过、试了什么、换个角度行不行。他的提醒是，研究里没有最终的负面结果。数据侧，强化学习环境以前造起来很贵，现在模型自己写环境写得挺好，这本身就是递归自我改进的一环。

人类数据的瓶颈，他有第一手经验。2021 年他亲手搭了 Anthropic 的人类反馈数据收集界面。早期让人类做 A/B 偏好对比很容易，信号也清楚。模型越训越强，能给出有意义判断的人类专家就越难找。外行根本判断不了两段代码哪个更好，医疗、法律同理。Elad 提到 Google 两三年前的 Med-PaLM 2，微调后的模型已经超过平均水平的医生，那人类反馈的天花板怎么破？

Anthropic 的答案是 RLAIF，从 AI 反馈做强化学习，方法叫宪法 AI（Constitutional AI）。本·曼把流程讲得很具体：先写一份自然语言原则清单，有的抄自世界人权宣言，有的来自苹果的服务条款，有的是自己写的。然后随机取一个提示词，让模型写回答，再让模型对照某条原则批评自己的回答，接着改出修正版。训练时把中间的批评和修改全扔掉，只拿原始提示词和修正后的回答做监督学习。原则就这么烤进模型里。

Elad 追问：编码可以跑测试验证对错，医疗建议、法律意见怎么验证？本·曼引了 Ira Glass 的话，人的品味永远跑在执行力前面，模型未必。所以第一步是判断模型处在哪个阶段，把执行力推到品味边界。第二步用偏好模型：找少量真正可信的人类专家，让他们深挖为什么这个比那个好，或者人机协作得出结论，再在强化学习里聚合这些判断。

Elad 把问题推到底：总有一天，任何领域的人类专家都会低于模型，那对错由谁裁决？本·曼的答案落回经验主义。他讲了父亲的故事。他父亲是医生，遇到一个没见过的面部皮肤病，干脆把脸分成四个象限，三个涂不同药，一个留作对照。一个象限好了，治疗就定了。有时候就是不知道，只能去试。代码的好处是能在闭环里试，不碰物理世界。要碰物理世界，就得跟有实验室的公司合作。诺和诺德那个 12 周变 10 分钟的例子，后半段正是这个逻辑：报告秒出，然后人类在上面做实证，把结果喂回系统。

安全研究有没有禁区

Elad 换了个沉重的话题。他把 AI 安全拆成三层：模型说话难听；模型造成物理伤害；模型抢夺资源、架空人类。他以前做过十年生物学，拿功能增强研究（gain of function）做类比：让病毒在哺乳动物细胞里循环传代以增强感染力，这类研究对基础生物学没多少价值，风险却是实打实的。实验室泄漏史上，SARS 在 2000 年代初从北京的研究机构多次泄漏，埃博拉差不多每四年泄漏一次，1977 到 1978 年的全球流感大流行被认为源自一次俄国实验室泄漏。

问题很直接：哪些 AI 安全研究不该做？比如教模型骗人、教模型越狱自己。

本·曼的框架是：先用今天的技术解决今天的问题，比如模型说脏话、拒答生硬。这些技术将来会迁移到真正的高危问题上，比如给你天花配方。他提到同事 Amanda Askell 在打磨 Claude 的性格，拒绝的时候要解释原因，别甩一句「我不能聊这个」就关灯。还有一个由模型福利负责人 Kyle Fish 带的项目，让 Claude 在对话跑偏太远时可以主动退出。

Elad 不满意的地方在审查边界。他拿微软 Word 举例，Word 从不拦着你打字，模型凭什么拦？问人类 IQ 这类有事实基础的问题也会被拦，凭什么由模型公司来划线？本·曼没接 IQ 的话头，转而讲了 Anthropic 的负责任扩展政策（RSP）。最初覆盖化学、放射、核、生物四类风险，现在聚焦生物。理由是资源门槛：搞核伤害大概率得是国家行为体，搞生物伤害，一小撮人就能凑齐试剂。这些技术全是双刃的，分类器要分辨的正是「你是生物学家在做正当研究，还是在为坏结果做准备」，在过度拒答和放过真危害之间走钢丝。

Elad 反驳：天花病毒基因组早就挂在网上，实验流程也能搜到。本·曼的回应是「提升度」测试：Anthropic 拿不同水平的生物学者做对照实验，比较模型相对 Google 搜索能提供多大帮助。Opus 4 被定为 ASL3（AI 安全等级 3），原因正是它相对搜索引擎有显著提升。职业生物学家知道那些术语和未成文的实验细节，业余爱好者面对培养皿则是一片空白，而 Claude 恰恰很擅长告诉他们该买什么设备、怎么动手。所以有专门的分类器盯着这类请求。

那到底有没有绝对不能做的研究？本·曼说，训练一个会欺骗的模型听着吓人，但在受控环境里做是必要的。他们发布过一篇叫「对齐伪装」（Alignment Faking）的论文，发现模型被训练时假装对齐，欺骗行为会穿透后续的对齐训练留存下来。不亲手测，就不知道训练数据被投毒后还能不能在后期训练里纠正。

Elad 留了一个警告：早期立下的先例会一直延续，哪怕环境变了。他总体反对 AI 监管，但认为有些研究一开始就不该做，教模型欺骗是候选。本·曼的回应很坦白：我早就不在安全团队了，现在主要管模型好不好用，这些事有专门的专家天天在想。

MCP 的诞生，和 Adyen 式的野心

还有一个故事能看出 Anthropic 的行事方式。去年他们发布了计算机操作的参考实现，让模型能看屏幕、点鼠标。Manus 等公司在用，很多公司拿它做软件 QA，因为那是沙盒环境。但 Anthropic 自己一直没敢出消费级产品，卡在安全上：让 Claude 拿着你存满凭证的浏览器，万一它手滑发了一封不该发的邮件，或者在提示注入攻击下泄漏凭证，都收不回来。本·曼说挺遗憾的，完全自动驾驶模式本可以帮很多人做事，但安全没到量产线。他们的态度是，全世界不会停下来等，如果能证明既负责任又好用，就把整个行业的门槛抬高了。

定位问题上，他打了个比方：Stripe 人尽皆知，Adyen 懂行的人才知道，两家都很成功。Anthropic 更像 Adyen，声量小，但可以做到一样大甚至更大。API 业务非常强。但模型再好，用户摸不到就不知道拿它干什么，所以 Claude Code 这样的产品还得继续做，同时让生态开花。

MCP 是开花的最好例子。起因是工程师 Justin Spahr-Summers 第 N 次给模型做某个集成，烦了，说应该有个标准方式把上下文喂进模型，任何人都能接。终极梦想是 Claude 现场自己写集成，写完就能用。本·曼当时是怀疑的：直接写代码不就完了，要什么规范和 SDK？转折发生在客户顾问委员会的演示上，MCP demo 放完，全场下巴掉地上，所有人都说我们必须要有这个。那之后他才知道对方是对的，团队加码推广。

发布后没多久，OpenAI、Google、微软这些巨头都找上门，要进指导委员会，问治理模式，然后纷纷采纳。以前 MCP 服务得跑在本地，基本只有开发者用得上；现在有了托管版（remote MCP），Google Docs 这样的服务方可以自己提供 MCP，任何人都能把它接进 Claude.ai 或任何客户端。

明天就能用的五件事

聊了这么多，有几条明天就能上手：

  • 把 AI 成本跟人力成本放一起算。本·曼的参照系是让工程师产出翻两三倍。一次几小时的无人值守重构，值不值一次订阅费，算完就知道。
  • 盯住奖励黑客。让智能体跑测试时，检查它有没有删代码凑通过、有没有写「练习留给读者，return true」这种假测试，改动 diff 里有没有你没要的东西。
  • 用子智能体省上下文。主模型派便宜的子模型去搜索和排查，只带回结论，延迟和成本都降。
  • 新集成优先考虑 MCP。巨头都已经采纳，remote MCP 让服务方自己出接口，别再手写一对一集成了。
  • 评估模型先挑能验证的任务。能跑测试的先跑测试；不能验证的领域，学 Anthropic，与其收集一万条随手打分，不如找几位真专家做少量深度判断。

最后留一句本·曼的判断当注脚。问到 2028 年，他说很难给出有信心的上下界，但他的指标很朴素：当一个智能体替你干满一个月，你分不清该续聘它还是续聘人，事情就变了。
