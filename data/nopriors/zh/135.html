《攻击只要23分钟，响应还按天算：Palo Alto CEO 把 AI 时代的生意和安全讲透了》

攻击者从锁定目标、突破防线到把数据拖走，七年前平均要三到四天。现在最快的一次，全程23分钟。而企业发现并响应一次入侵，平均耗时仍然按天计。

这组数字来自 Nikesh Arora（尼克什·阿罗拉），网络安全公司 Palo Alto Networks 的 CEO，最近做客 Sarah Guo 和 Elad Gil 的播客 No Priors。他2018年接手 Palo Alto 时，公司还只是一家卖下一代防火墙的厂商，七年间规模做到原来的六七倍，成了平台型安全公司。再往前，2004到2014年他是谷歌的首席商务官，全程经历了谷歌增长最猛的十年。

一个管过谷歌生意、又把安全公司做大七倍的人，聊 AI 对商业的冲击，每个判断背后都有真金白银的痕迹。这期节目信息量很大，下面挑最硬的说。

搜索的命门在商业模式

Sarah 开场就把尖锐问题扔过来：搜索还有未来吗，谷歌到底危不危险？

阿罗拉先给搜索正名。过去二十年，搜索干成了一件事，把全世界的信息搬上网，让所有人都能拿到，印度的农民也能查资料，这是信息的平权。现在进入新阶段，信息多到没人想自己筛，大家要的是有人直接把结论端上来。他给这件事起了个名字，叫「智能的平权」。

同一个问题已经被解决过9999次，第一万次就不该再花钱雇人重做，答案早就在网上。生成式 AI 做的就是把这几千个答案合成一个。

他回忆，15年前拉里·佩奇就在讲，搜索的终局是理解意图，直接回答用户想问的事，别再机械匹配输入的字符串。方向谷歌早就看对了，Gemini 也在往这个方向走。再加上分发优势，全世界握着几十亿用户入口的公司只有两三家，Facebook、苹果、谷歌，产品能力和 AI 能力它们都有。

真正的悬念在钱上。搜索的收入靠文字链广告，用户搜「世界上最好的蓝色裤子」，背后是购买意图，广告主为意图出价。Agent 时代，用户直接让 AI 把裤子买了、把机票订了。广告卖的是线索，成交比线索值钱得多，直接促成交易理应收到更多钱。从线索费走向交易分成，可能是那条出路。

但阿罗拉也承认，没人知道新商业模式长什么样。他举了 YouTube 的例子：很多年里所有人都看不懂 YouTube 怎么赚钱，风光属于 Netflix，现在 YouTube 已经是比绝大多数流媒体玩家都大的生意。谷歌的习惯是先让产品被几十亿人用起来，模式最后会自己长出来。

Agent 才是真颠覆

整期节目里他最重的判断是这条：Agent 带来的冲击，比生成式 AI 本身大得多。

推理从产品史出发。过去三四十年，软件公司都在打磨 UI，产品经理本质上是个「高级 UI 经理」，帮普通人跟背后的工程算法对话。Expedia 就是几个填空框，因为总不能让用户自己写 SQL 查机票。生成式 AI 让人能用自然语言跟 UI 对话，前进了一步。再往前一步，人干脆不用来了，派个 Agent 替你办。

他估了个数：两大手机生态加起来至少500万个应用，其中一半左右本质上是「交易履约应用」，存在的意义就是让人填表、下单、拿结果。如果 Agent 直接替人完成交易，这些应用凭什么继续霸占用户的屏幕？

Elad 追问谁最危险。答案很干脆：对 UI 没有忠诚度、只是交易系统上一层薄薄前端的生意最危险。你在乎机票从哪家网站订的吗？不在乎，你只想到达目的地。你在乎谁帮你订餐厅吗？也不在乎。

接下来会有一段混乱期，大量应用被重写，有些会退化成纯接口，变成 MCP 客户端和服务端之间的调用，用他的话说，以后都不叫 API 了。等这轮重写结束，谁坐在所有 Agent 的最上层，谁就是下一个 Uber。

现实已经走到前面了。他说自己跟几家大云厂商开会讨论怎么保障 Agent 安全，结果连 Agent 的定义都没共识：有的说要走 MCP 协议，有的说就是个连接器，追问下去，连接器其实就是过去的 API 调用。身份怎么注册、权限怎么委托，全都没答案。Palo Alto 内部有个小组每天花两小时读所有新东西，靠六七个人的集体判断拼出 AI 演化图景，再据此设计产品。

企业不会为聪明付费，会为记录付费

Sarah 提到两个正在被验证的商业模式：消费者订阅智能，以及企业按「单位工作量」付费，模型解出一个难题收一份钱，实验室想卖的是劳动本身。

消费者订阅的进展超出很多人预料，愿意为智能付月费的人比想象中多。企业这边，阿罗拉泼了盆冷水，核心差别在容错率。消费者搜不到答案会怪自己没问好，换个问法再来。企业零容忍。他举了个例子：你让 LLM 关服务器，它关错了台，整个业务宕机，然后跟你说「不好意思，我理解错了」。

今天没有任何企业敢把自主权交给 LLM，所有 AI 都在人的监督下当助手，干的都是允许出多个答案的活。等哪天模型能稳定输出精准任务、精准动作，按工作量收费才成立。计费单位是什么，按席位、按 Agent 席位还是按工作量，他也不确定，反正会有一个。

他判断企业软件会演化出一种新形态，可以叫「AI 即服务」，接替 SaaS。参考对象是 Cursor 这类产品：先接住开发者工作流的一段，用得越久越懂你，慢慢接管更多任务。用他的话说，现在的 AI 应用都还在培训期，长大了会接管越来越多的重复劳动。

这里有个更根本的判断。各家模型的推理能力在收敛，越来越接近。企业用最聪明的模型，相当于招了全世界最聪明的博士：

这个博士再聪明，走进 Palo Alto 的门也不会干活。他得先学我们怎么做事，理解我们的上下文。模型也一样，得喂大量领域数据，才能在领域里变聪明。

代码是特例，公开代码足够多，模型自学就能到90分。基因数据、制药研发数据、网络安全数据，公开领域都没有，谁握着专有数据谁有牌。他记得自己最早打给谷歌云 CEO 托马斯·库里安的电话里，对方劝他别做安全专用小模型，大模型会越来越聪明，小模型追不上。后来有竞品高调宣布做网络安全专用模型，至今没下文，Palo Alto 因此没走这条路。

所以他给 AI 应用创业者划了条生死线：产品如果只是给模型加壳，增强点能力、加点护栏，模型每升级一次就把你的能力吃掉一点，最后直接出局。有人说要做 AI 帮忙分析法律合同，可他自己拿 ChatGPT 分析合同，效果已经够用。能活下来的 AI 应用要学 SaaS 的老套路，把工作流和「记录系统」绑在一起。HR 系统为什么换不掉？工资、假期、期权、归属日期全在里面。模型永远成不了记录系统，记录系统还是那堆专有数据，只是交互界面从表单换成了 Agent。

他对内部团队的要求更直接：法务审查、应付账款处理这类通用型 AI 应用，一律别自己造，肯定有人做出来卖给所有人，租比建便宜。唯一的功课是把好安全关。他们采购任何 AI 应用前，一半时间花在问安全问题上：我的数据是不是我的？你拿去训练了吗？问完还要实测验证。FDA 试验数据、源代码这种东西，绝不能在多租户环境里帮别人训练模型。

至于自己公司内部，他的预期是：销售不会变，AI Agent 短期内说服不了 CIO，人还得上门，倒是会冒出「拦截所有推销」的收件箱 Agent，把群发邮件一锅端；行政类岗位最先被压缩，200个做文档的人，模型干90%，留下懂 AI 的人写护栏和模板，整体效率能抠出200到400个基点；还有一堆没人愿意维护的老代码，Salesforce、SAP 的技术债，正好让 Agent 去清。变化最大的是客户支持：

客户支持存在的原因，是我们把产品做坏了。产品足够好，要客户支持干什么？

他把客服团队挪到产品团队旁边，立了规矩，出了 bug 先修 bug，再谈新功能。他的目标是未来两到五年，全行业把80%到90%的客服工作消掉。他见过 vibe coding 工具在自家安全代码里找出一个漏洞，这种问题往常要等暴露在真实攻击里才会被发现；见过500行代码被压到75行；见过15年前的无注释老代码被逐行讲清用途。他也补了一句，愚蠢没有解药，没有好人把关、没有护栏流程，AI 只会更快生产垃圾。他还反问，谁愿意让孩子长大去干客服？听人抱怨、挨骂，还没有权限解决问题，像被人打了一拳却不能还手。这种工作消失，天经地义。

攻击只要23分钟，响应还按天算

聊到安全威胁，他给的数字最扎心。七年前他刚到 Palo Alto，攻击者从锁定目标、突破、到拖走数据，平均要三到四天。现在最快纪录是23分钟。攻防变成一道物理题：对方一小时内能进出自如，你的响应速度就必须小于一小时，而行业平均响应时间还停留在按天计。AI 压缩的是攻击者的时间线，这是他眼里 AI 带来的最大威胁。

入口也没好到哪去。89% 的攻击始于凭证窃取，也就是坏人变成了「你」。深度伪造、AI 生成的鱼叉邮件、语音克隆，把社会工程学的门槛打到地板上。他拿自己举例：某家银行打电话让他确认身份，问三个冷僻的个人信息问题，这种验证，ChatGPT 扫一遍公开信息就能答上来。大多数双因素认证，在 AI 面前会陆续失效。

渗透测试同样在被重写。他吐槽，一半企业不做渗透测试是因为怕查出问题，只做最低限度的合规。现在自动化渗透测试已经能像真攻击者一样全年无休连续打。Palo Alto 自己就这么干，7×24小时给自己找漏洞，安全公司被攻破就是灾难。

防守思路也得换。他的主张是别死磕「守住每一次身份验证」，要盯行为：与其保证 Sarah 的账号永远不被盗，不如盯住 Sarah 的行为是否异常。一个七年来每天只收发邮件的人，突然开始批量下载数据，直接拦。节目里 Sarah 顺嘴接了句「这事上周真发生过」，全场笑场。

这也是他们收购身份安全公司的逻辑。传统身份产品是进门查一次，之后在企业里随便逛。他要把「永久权限」改成「即时权限」，用时才授权，行为异常就掐断。他甚至说，以后可能连第二验证因素都省了，看你打字的节奏就知道是不是本人，节奏变了就拦。

118个工具的碎片化，就是平台的机会

Elad 转述了一位大型金融机构安全负责人的处境：光身份类工具就有118个。阿罗拉接梗，这行有个天然的「身份危机」。

碎片化是历史遗留。网络安全是科技行业里最年轻的行业，只有25年历史，网络出现之前根本不存在这回事。每冒出一个新威胁，就有人创业做个点状工具，堆到今天，就是每家企业几十上百个供应商、同一份数据被反复采集分析的局面。

但工具会商品化。他的原话很扎心：造防火墙没有任何天才之处，市面上所有防火墙的性能差异在正负10%以内。80% 的能力会沉淀进统一平台，剩下20% 以插件形式存在，平台再不断把新的20%吃进来。一年前还没人谈 AI 安全，现在一窝蜂的公司在做提示注入防护、模型恶意软件扫描、数据投毒检测、Agent 攻击防御，这些最后都会变成平台的功能项。

Palo Alto 的平台逻辑分两层。第一层是卡位。安全行业有句行话，看不见就拦不住，所以必须部署在每一个边缘、每一个终端、每一个传感器上。五年前他们定下策略，尽可能多占控制点，SASE 和终端产品就是这么来的。传感器拦「已知的坏」，但大多数入侵来自「未知的坏」。

第二层是数据。他举了个典型场景：一封钓鱼邮件进了公司，邮件网关看着可疑，只给出「建议调查」；员工点了链接，流量穿过防火墙，凭证被偷，防火墙压根不知道前面发生过什么。各家工具各管一段，没人拼得出完整故事。客户不需要5000条待调查清单，客户要答案。所以他们的路线是把企业全量数据收拢，在数据入口处就跑机器学习做交叉分析，直接还原攻击链条。

对标成熟行业，他的论据更直白：CRM、ERP、HR 早就收敛成单一平台，没有企业同时跑两套 SAP。安全行业迟早走到同一步。他接手时公司只有4个产品，后来扩到24个，Gartner 魔力象限和 Forrester Wave 上榜44次，现在整合成三大平台。他给客户的预期是两三年部署一个平台，从118个工具到3个平台，总得给过渡。

这套打法背后有一笔账。收入10亿美元以下的企业软件公司，销售、市场、客户支持加起来吃掉成本的50%到65%，几乎没有利润空间；最大的企业软件公司，这个比例是30%。研发占比稳定在12%到16%，管理费用4%到8%。利润杠杆全在销售效率上，也就是在一个客户身上建立信任之后持续扩展的能力。这就是他执意做平台的原因：销售好不容易敲开客户的门，客户说防火墙够用五年，这单就死了。货架够宽，销售才有的卖。

并购是平台的另一半。到目前为止买了27家公司，正在等审批的这笔是史上最大，身份安全公司 CyberArk。他不叫它并购，叫「分布式的研发」，还顺带感谢了 VC 生态：风投出钱替他试错，他只收头部成果。原则有三条：只买品类第一第二，第三第四打磨得再亮也不碰；被收购公司的创始人多半留下来继续带队，因为他们证明了比自己更快的执行力；补短板要快，他们做了 AI 防火墙保护企业租用的模型实例，回头发现模型本身的评估和持续红队测试自己没做，模型输出是不确定的，同一个问题一周后可能给出不同答案，每条输出都得查有没有恶意内容，这块能力直接靠收购 Protect AI 补齐。

管理课：把高管会从8人扩到25人

节目最后聊管理，阿罗拉的方法论朴素到近乎反高潮。

他说从拉里·佩奇那里学到最重要的一课：科技公司一旦丢了产品，就会慢慢衰亡。所以他到 Palo Alto 先研究产品和商业结构，再谈战略。选生意也只选增长市场，市场足够大，公司才有抢份额的空间，他讨厌去重组一条下坠的曲线。

管理上他信一个前提：没有人早上起床是奔着把事搞砸去的。人才到处都有，好公司和差公司的差别在于，有没有讲清楚北极星，有没有让人真心买账，讲没讲清楚「为什么做」而不只是「做什么」，有没有给够资源。他的角色是定战略、找对人，然后给团队当盾牌，把摩擦和破事挡在外面。

他抄了黄仁勋的作业。黄仁勋有40个直接汇报，不做一对一。阿罗拉看到后把自己的高管会从8个人扩到25个人，理由很实际：高管向下传达时经常丢掉「为什么」，一层转述一层模糊，直接讲给25个人听，至少消灭一层失真。

还有一个习惯，每两周见50名一线员工，随便聊。他由此发现，隔了四五层的员工根本不理解公司在做什么、为什么做，于是动作变形，或者干脆不做。沟通是组织里最被低估的事。他也坦白，股价七年涨了六七倍，内部质疑战略的声音自然就少了，野心需要成绩单背书。

明天就能用上的几件事

把节目里的判断翻译成动作：

  • 重设响应时间预算。假设攻击者一小时内能完成入侵和数据窃取，把「发现到处置」的流程按分钟演练一遍，跑不进一小时，先补最慢的那一环。
  • 改权限模型。把「进门发永久通行证」换成「用时授权」，部署行为异常检测，重点盯批量下载、异常时段访问这类动作。
  • 采购 AI 先过三问。数据存在哪、是否拿我的数据训练、能否独立验证。问完还不够，要像 Palo Alto 一样实测。
  • 通用 AI 应用一律租。法务、应付账款、文档处理别自建，省下的资源投给有专有数据的领域，并把 AI 能力绑进自己的记录系统，那是模型吃不掉的护城河。
  • 清点安全工具。118个工具不会一夜变成1个，但可以今天开始排收敛顺序，先合并功能重合的那批。
  • 做 AI 产品先自问。模型下次升级会不会顺手把我的功能做掉？答案含糊，就赶紧往工作流和记录系统里扎。
  • 管理者做两件小事。把高管会扩容，亲自把「为什么」讲给更多人听；每两周固定见一批一线员工，检验信息在第几层丢的。

节目结尾，阿罗拉说自己整体乐观，历史上每次技术革命都是双刃剑，好人比坏人多，人类连疫情都扛过来了。乐观归乐观，23分钟这个数字，值得每家公司的安全负责人贴在工位上。
