《每 7 到 10 天新增 100 万美元收入，Warp CEO 说图灵测试已经悄悄过了》

图灵测试，1950 年图灵留下的那道题：如果人类分不清对面是机器还是人，这台机器就算达到了人类的智能水平。Warp 联合创始人兼 CEO Zach Lloyd 在 2025 年 10 月下旬上线的 No Priors 播客里给出判断，这个测试已经通过了。

他的原话更值得咀嚼：

「让我觉得疯狂的是，我们刚刚通过了它，居然没人在意。」

Zach 的背景在科技圈算少数派：他有科学哲学的硕士学位，在 Google 做过 Google Sheets，创办 Warp 之前还创过另一家公司。这期节目由投资人 Sarah Guo 和连续创业者 Elad Gil 主持，Sarah 报了一组数据：Warp 月活用户接近 100 万，每 7 到 10 天新增大约 100 万美元收入。这家公司从开发者终端起家，现在做的是 AI 编程代理平台。

整期节目分两半，前半段聊 AI 有没有意识，后半段聊开发者工具市场怎么打。两边都有能记笔记的东西。

图灵测试过了，没人开香槟

Zach 对这波 AI 的定义只有一句话：我们在蒸馏智能。像酿酒的蒸馏工序，把智能从人类积累的文本里提纯出来，装进一个随取随用的容器。有人担心我们在再造人、再造意识，他觉得问错了问题，真正发生的事叫蒸馏智能。让他着迷的点是，仅仅靠预测下一个词，模型就能表现出这么多智能。这反过来引出一个问题：人脑是不是也在做同样的事？他的答案是否定的，他相信模型后面还有更大的解锁。

他推荐了一本书，加拿大科幻作家彼得·瓦茨的《盲视》。书里的设定是人类在太空遇到一个智慧存在，它会造飞船、能交流、能解决问题，但没有意识，人类要琢磨的是怎么跟这样的东西沟通。Zach 说这就是他眼中当前 AI 的样子：从功能角度看，它能做我们承认是智能的事，但它完全是机械的。没有任何人看着这些模型，会认为里面有意识存在。

人类给机器出题的历史也值得回味。下棋，机器赢了，我们说下棋不算数。下围棋，又赢了，还是不算数。打游戏，也赢了。每出一道题，机器通过，我们就换一道，然后继续说它没意识。

Sarah 把矛盾挑明了：图灵测试是机械的标准，下棋、围棋也都是机械的标准，机器通过了，我们又不认账，那到底要怎么测意识？Zach 坦承这是个大问题，他没有好答案，但他给了一条观察路径：记忆。一个人可以失去记忆还保持清醒，所以记忆算不上意识的前提。现在的模型会推理，会理解语言，会综合知识和想法，缺的可能是别的东西。它们被喂进一串 token，吐出一串 token，然后被关掉。没有持续的感觉输入，没有跟世界的实时反馈回路。

Zach 猜，第一个被大家承认「更有点意识」的 AI，大概长得更像机器人：有摄像头，有传感器，对眼前发生的事实时反应。但他紧接着给了一个更扎心的判断：只要我们完全知道它内部的运作机制，我们就不会承认它有意识。这对机器不公平，因为人脑大概率也是一堆机制在跑，无非是矩阵运算和层层嵌套的函数。

他有个读哲学博士的朋友，正在写论文，说跟 GPT-5 聊天比跟导师聊收获还大，原话是「GPT-5 懂我」。

这种感受已经酿成过真实事件。Warp 就遇到过用户坚信它家的 AI 有意识，反应非常激烈。更早的例子在 Google，2022 年，工程师 Blake Lemoine 认定内部对话模型 LaMDA 有意识，把聊天记录公之于众，随后被公司解雇。Elad 在节目里点出这件事的分量：一旦 AI 真的有意识，怎么对待它就成了伦理问题，操纵它、伤害它，都会变成需要严肃对待的事。

一个 40 年没变的工具，凭什么重做一遍

聊回生意。Warp 做的东西叫终端，就是开发者每天敲命令行的那个界面。很多人对它没概念，可以这么理解：程序员跟电脑说「编译这个项目」「重启那个服务」，就是在终端里打字完成的。

Zach 给它列了两面。一面：每个开发者每天都用，跟代码编辑器并列；练熟之后效率极高；横跨软件开发的各个环节，写代码之外的事也归它管。另一面：40 年基本没变过，难学、难记、吓人，还带着一股「不会用就别进来」的门禁气质。

Warp 现在给自己的定位叫「代理式开发环境」。你可以用终端命令跟电脑说话，这是老产品；也可以直接用英语说，这时它会启动一个 agent 去干活，写代码、搭项目、服务器崩了现场调试，都行。Zach 强调这是个横着的、通用的界面，开发者在这里告诉电脑要做什么，用命令也行，用人话也行。

竞品大概分几类：Cursor 这类从 IDE 起家的，Cognition 那种在网页端跑任务的，还有 Claude Code，从终端切入但就是个纯文本工具。Warp 卡的位置有点特别：它有命令行，但它是个图形化的外壳应用，所以编辑功能、代码评审界面这些体验，它都能自己做主。

增长拐点出现在访谈前的三四个月。Zach 回忆，Warp 有很长一段时间被叫作「AI 终端」，支持 Docker、Git 这类命令行场景做得不错，但真正的动作在编程。绝大多数开发活动，绕来绕去都要碰代码库。一个强大的编程 agent 上线之后，数据就起来了。

商业模型也换过一次血。最早的设想是围绕终端做协作平台，后来发现市场对 agent 平台的需求大得多，就切了过去。

目标用户他也挑得很清楚。现在人人都能用 AI 生成应用，他觉得这很棒，但 Warp 瞄的是专业开发者写的那种「有经济价值的软件」，会钉在 Mac Dock 里，或者常年固定在浏览器标签页上的那种。他的判断是，软件市场的价值集中在少数被重度使用的应用里，他自己就做过这种应用，Google Sheets。让 agent 用几个提示词生成一个网页应用，现在已经不难；把 agent 用好到专业代码库上，难得多。Warp 选了难的那边。

写代码的三个阶段

Zach 把开发方式的演进分成三段。

  • 第一阶段，手写。打开编辑器，找到要改的文件，敲代码，回到终端构建。他职业生涯的大部分时间都这么干。
  • 第二阶段，按提示词开发。他现在的大部分编码任务，都从给 agent 写一段提示词开始，让它干活，中途看一眼，随时改方向。
  • 第三阶段，自动开发。服务器报错，agent 自己处理；用户提交工单，agent 自己跟进。Cognition 在做这个，Cursor 有后台 agent，Warp 也在进。

Elad 在这里引了科技行业一句老话：三年里发生的事，总比你以为的少；五年里发生的事，总比你以为的多。ChatGPT 2022 年 11 月发布，当时「五年内一切被 AI 接管」的预言没兑现，但方向没错。

速度 Zach 不敢打包票。他观察到一个现象：最近几代模型的提升，没有 Sonnet 4 发布那次那么大。他的预测是，一两年内所有人都会进入「按提示词开发」，同时有一小块开发任务会在后台自动跑，但不会是全部。交互式开发和自动开发会并存相当长时间。

Sarah 追问：会不会有一天所有编码都由 agent 完成，人类只负责给方向，像个产品经理或者工程经理？Zach 的回答是，也许吧，不把这套基础设施建出来反而傻。但时间点，他说不准。

生意角度他还补了一层：自动化比提效是好得多的位置。提效类产品最难的事是证明 ROI，有研究显示，把 AI 编程工具部署到真实代码库上，效果到底有多大其实说不清。自动化不一样，结果摆在那里，而且不受键盘时间限制，天花板也更高。

Agent 是初级工程师，资深经验反而涨价了

Zach 打了个比方：现在的 agent，就是一群初级工程师。没有资深的人盯着，它们写出的代码会埋 bug，会带安全漏洞，会让整个代码库慢慢变得没法维护。

所以市场上出现了一个反向行情：架构能力、代码评审能力、保证系统不腐烂的能力，这些资深工程师的技能，眼下比以往任何时候都值钱。他给职业早期的人的建议非常直接：

「如果我刚入行，我会拼命去攒这些资深能力。最不该待的位置，是永远停在初级工程师的状态，那个位置确实有风险。」

顺着这个逻辑，安全工具的价值也在涨。Socket、Snyk 这类做漏洞扫描的公司，还有 Rust 这种默认安全的语言，在 agent 大量产码的时代都会更吃香。理由很朴素：机器生成的代码量暴涨，靠人眼逐行审已经不现实了，能自动做安全分析和验证的东西会变成刚需。

至于这些能力最后长在哪里，Zach 的看法分两层。前端那一层，Lovable、Bolt、Replit、Figma Make 这些，会变成一站式平台，建应用、接支付一条龙，类似 Shopify 或 WordPress 的进化版。专业开发这一层，他押注整合：你费劲训练出一个很强的编程 agent，它理应顺手把代码评审做了，再外挂一个工具让它重新学习整个代码库的规则和惯例，说不过去。安全检查、代码评审、CI 这些活，都应该长在拥有完整上下文的那个系统里。

整合的路线也有分岔。一条是 MCP 加各种集成，工具之间互相调用；另一条是把所有东西装进一个窗口，Warp 走的是后面这条，本地 agent 和远程 agent 都在一个界面里管。Zach 认为 MCP 有价值，但有硬伤：数据经过中转，进到工具里的已经是二手信息。

Elad 补了一条行业规律：一个行业早期碎片化，成熟后走向捆绑，技术革命来了又拆散，然后重新捆绑。按这个节奏，现在市场上这一批只做单一功能的工具公司，最后会收敛到少数几个玩家手里。Zach 认同，还补了两个关键词：模型外面那层壳，和壳里积累的上下文，才是核心资产。

模型公司会不会把桌子掀了

Elad 抛出了所有 AI 创业者都会失眠的问题。历史上，平台总把最赚钱的应用收编进自己怀里：微软把使用最多的那几个应用捆进 Windows，游戏是另一个大头，所以后来有了 Xbox；Google 把各种垂直搜索整合进主页。今天的模型公司正在复刻这个剧本：Anthropic 有 Claude Code，OpenAI 差点买下 Windsurf，还推出了 Codex，微软手里攥着 GitHub 和 Copilot。

Zach 承认，作为创业者，这确实有点吓人。但他认为这次有个关键差异：编程这个场景的「入口」还没被模型公司攥在手里。微软当年的优势在于所有人都得用 Windows，所有人都从 Google 进互联网，第一方应用顶掉生态产品很容易。而开发者干活的地方，目前仍然是一个装在电脑上的原生应用，终端或者 IDE。谁控制这个入口，谁就有位置优势。GitHub 明明是所有源代码的所在地，理论上是最佳阵地，但他的评价是，微软在那儿执行得不算好。

现在市场的真实画面有点滑稽：很多用户在 Warp 里面跑 Claude Code，Warp 是外面那层壳。

他的另一张牌押在模型层商品化上。目前模型公司有定价权，因为旗舰模型和开源模型之间有实打实的差距。Warp 和 Anthropic 是重要合作伙伴，投了不少资源把自己做成 SWE-bench 上的头部 agent，他们看到的曲线是：Sonnet 3.7 升到 4 那次是大跳，4 升到 4.5 只涨了几个百分点，GPT-5 延迟更高，整体感觉没到换代级别。瓶颈正在从推理能力转移到上下文：读懂整个代码库、读懂代码之外的资料、读懂用户到底想要什么，这些还是难题。

所以 Zach 的赌注是：如果有一天模型好到让编程「够用了」，开发者不再非用旗舰模型不可，智能 token 变成大宗商品，模型公司的优势就只剩品牌和规模，远不如 Windows 或者 Google 首页那种入口地位牢固。

消费级市场他倒是认输认得干脆。ChatGPT 已经成了很多人的默认动作，就算 Claude 更好，多数人也不会换。OpenAI 开发者日上刚发布的 ChatGPT 内应用平台，摆明了要用数据把最好的第三方功能收编成自家功能。只是这套打法，在开发者市场还没跑通。

明天就能用上的四件事

这期节目的信息密度不低，挑四件明天就能动手的。

  • 刚入行的工程师，把时间押在架构和代码评审上。agent 负责产出，人负责兜底，兜底的能力正在涨价，停在初级状态才是真正的风险。
  • 把 agent 当新人带。给它立规矩、审它的产出、定期回头看它改过的代码，跟带实习生一个流程。
  • 把最讨厌的重复劳动交给后台 agent。Zach 举的例子是文档同步：每次代码更新，headless（无界面）agent 挂在 CI 里自动把文档改到最新。这类活没人爱干，机器干正合适。
  • 评估 AI 编程工具时算结果账，不算感觉账。提效类产品的 ROI 很难证明，自动化类，自动修 bug、自动跟工单，账好算得多。买工具之前先想清楚要的是哪种。

最后回到那个哲学问题。图灵测试过了，没人开香槟，因为大家心里清楚，智能和意识是两回事。机器把智能这一侧越推越远，意识那一侧还空着。至于那一边什么时候、以什么方式被填上，Zach 自己也承认，他不知道。
