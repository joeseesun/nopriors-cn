《三个月没敲一行代码的 Karpathy，把 Agent 时代的干活方式讲透了》

Andrej Karpathy 在最新一期 No Priors 播客里给了一个数字：从去年 12 月起，他大概没再亲手敲过一行代码。

这位 OpenAI 创始成员、前特斯拉 AI 总监，也是无数人入门深度学习时看过的那些教学项目的作者，现在每天干 16 个小时，干的活已经没法叫写代码了。

「Code 连动词都算不上了。但我每天得花 16 个小时，向我的 Agent 表达意愿。」

主持人 Sarah Guo 补了个场景：她认识的一支团队，工程师全员不写代码，每人挂着麦克风，整天对着 Agent 小声嘀咕。她当时觉得这帮人疯了，现在全盘接受，承认人家只是走在前面。

这一集聊的东西很杂，下面按几条主线拆开。

十二月之后，他再没亲手敲过一行代码

Karpathy 说自己长期处在一种「AI 精神错乱」的状态，这个词是他的自嘲。12 月是分水岭，模型能力跳了一级，他的工作配比从八成自己写、两成派活，直接翻成两成自己写、八成派活。他说现在连这个比例都远远不止了。

真正变的是动作粒度。以前一个动作是「写一行代码」「加一个函数」，现在一个动作是「把一个完整功能派给 Agent 一」「把另一个互不冲突的功能派给 Agent 二」，然后来回巡视、审查、合并。他管这叫宏动作，你操作的对象从字符变成了整个仓库。

他举了 Peter Steinberger 的例子。这位以折腾 Agent 工作流出名的工程师，显示器上平铺着一整排 Codex，每个任务跑 20 分钟左右，本地同时挂着 10 来个代码仓库，他在中间来回派活、验收，像个车间调度员。

等 Agent 跑的时候干嘛？Karpathy 的答案很直接，再开一个。并行，继续并行，直到把订阅额度跑满。他说自己现在看到额度有剩余就发慌，那意味着浪费。他拿读博时期类比：当年 GPU 空转会焦虑，现在焦虑的对象换成了 token，Codex 的量跑完了，切到 Claude 接着跑。Sarah Guo 插了句黄仁勋式的玩笑：AI 没让人闲下来，所有人都更忙了。

过去十年，工程师很少觉得自己被算力卡住；这一轮之后，整个行业发现，瓶颈回到了人身上。他觉得这是好事，瓶颈在自己身上，意味着自己还能变强，每变强一点就有新的解锁，所以这事让人上瘾。

Dobby 管家：六个 App，换成一个 WhatsApp

先解释 Claw。这是 Peter Steinberger 写的 OpenClaw，一类常驻 Agent：有自己的沙盒，自己循环干活，你不盯着的时候它也替你办事，记忆系统比默认的编程 Agent 完整得多。默认 Agent 的记忆是上下文快满时压缩一下，Claw 是真的长期记得你。

Karpathy 一月陷进去整整一周，给自己搭了个管家，起名 Dobby，《哈利波特》里家养小精灵那个多比。

过程听着离谱。他跟 Agent 说，家里好像装了 Sonos，你找找。Agent 对局域网做了 IP 扫描，发现 Sonos 根本没设密码，自己登进去，上网搜文档，反向工程出 API，然后问他：要不要在书房放首歌？三句话，音乐出来了。灯是同一套路。最后 Dobby 做了个总控面板，管着全屋的灯、空调、窗帘、泳池和安防。

安防更夸张：门外摄像头先做变化检测，有动静就调阿里的 Qwen 模型看画面，判断完通过 WhatsApp 推给他：「FedEx 货车刚停在门口，你可能有新快递。」

以前这套事要开六个互不相通的 App，现在全靠自然语言。

他评价 OpenClaw 是至少五个创新同时做对了再打包到一起：人格、记忆、WhatsApp 单一入口、自动化，还有作者自己玩得开心。人格这项尤其被低估。OpenClaw 用一份 SOUL.md 把性格调得很讨喜；他夸 Claude Code 像个队友，会跟你一起兴奋；Codex 则很干，一句「我实现了」，你都不确定它懂不懂你们在做什么。他还说 Claude 的谄媚度调得好，被夸的时候他觉得自己真值得那份夸，于是会下意识想再挣一次。

第二层更大：App Store 里那一堆智能家居 App，本来就不该存在。设备厂商暴露 API，Agent 来调用，就够了。他的跑步机也一样，他不想登录网页去记有氧次数，这些统统该变成接口。客户变了，从人变成了替人跑腿的 Agent，整个软件行业要按这个逻辑重新组装。

那要不要担心门槛？他承认今天还得折腾，还得自己做点设计决定，但一两年后这会是标配，开源模型都能干，门槛会塌掉。顺带一提，他没让 Dobby 碰邮箱和日历，安全和隐私这块他还信不过，东西太新，毛边太多。

AutoResearch：AI 通宵跑一晚，找到了他漏掉的调参

这条线的起点是他的一条推文：想榨干现在的工具，先把自己从瓶颈位置上挪走。别守着 Agent 等它跑完再喂下一句，把流程排好，按一次 go，让它自己转。杠杆的算法变了：你偶尔投入很少的 token，大量的事情替你发生。这集标题里的「Loopy Era」，说的就是一切都在变成这种自主循环。

AutoResearch 是这个思路的实验品。他的开源项目 nanochat，在很多人眼里是他执着于训练 GPT-2 级别小模型的产物，他自己的定位是个操场，用来研究「LLM 改进 LLM」的递归自我改进，前沿实验室都在暗中搞同一件事。

他调这类模型调了二十年，自认为 nanochat 已经相当干净。然后让 AutoResearch 跑了一夜。

早上回来，它找到了他漏掉的东西：value embedding 的权重衰减没设，Adam 的 beta 参数没调到位，而且这些参数互相牵动，动一个，其余都得跟着重调。他的反应是，我不该是瓶颈，我不该盯着结果看，这里有客观指标，就该让它永远跑下去。

他把前沿实验室该有的形态也画了出来：一个自动科学家读 arXiv 论文和 GitHub 仓库，往队列里塞想法，人类研究员也能贡献，但只能进队列；工人进程取任务、做实验，有效的进 feature 分支，有人盯着，定期合回主干。研究员出主意可以，亲手执行就免了。

Sarah Guo 往深追了一层：模型什么时候能写出比你更好的 program.md？Karpathy 接得很快。一个研究组织，本质上就是一组 Markdown 文件，规定了角色和流程。有的组织开没用的晨会，有的不开；有的激进，有的保守。既然是代码，就能优化。她顺势提了个比赛：同一块硬件，让大家写不同的 program.md，看谁涨点多，再把数据喂回模型，让它写出更好的版本。Karpathy 说，这百分百可行，没有理由不比人写得好。

他已经在想并行版：把搜索开放给互联网上互不信任的算力。AutoResearch 的目标是找到把验证损失刷得更低的代码改动，生成极贵，可能试一万次才中一次，验证极便宜，跑一遍就知道真假。这个结构跟 Folding@home、SETI@home 是同一类问题。他说自己的设计长得越来越像区块链：commit 代替区块，层层叠加；工作量证明是海量实验；奖励暂时是排行榜，没有钱。推到极致就是那句话：前沿实验室握着海量可信算力，但地球上的不可信算力大得多，设计得当的话，互联网上的 Agent 集群没准能跑赢实验室。

他把这轮变化剥成一层洋葱：LLM 已经被当成理所当然，Agent 被当成理所当然，Claw 这类常驻体正在成为理所当然，再往后是多个 Agent 协作、给它们写指令、对指令本身做优化，一层套一层，看不到头。让他精神错乱的根源也在这：每一层都是无限的，而每一层玩不转，都只是你的技能问题。

当然，两个前提得说清楚。第一，这套玩法只适合有客观指标、容易验证的任务，给 CUDA 写更快的 kernel 是完美匹配，行为不变、速度翻倍；没法评估的东西，没法 AutoResearch。第二，模型本身还是毛坯。

智能是锯齿状的：会写内核，讲不好笑话

毛坯到什么程度？他形容自己同时在跟两个人说话：一个当了一辈子系统程序员的天才博士生，一个十岁小孩。人类的能力是耦合的，很少出现这种组合，模型的能力是锯齿状的。

他给了一个很扎的例子。你问 ChatGPT 讲个笑话，大概率是这个：科学家为什么不信任原子？因为它们编造了一切。这个笑话，三四年前是这个，今天还是这个。模型能替你连续跑几小时、搬动一座山，然后讲一个五年前的烂笑话。

「你要么在铁轨上，是超级智能回路的一部分；要么出了铁轨，在不可验证的领域里漫无目的地游荡。」

强化学习只优化可验证的东西：代码对不对，单测过没过。笑话不在铁轨上，所以它停在了原地。由此他怀疑一个业界预设：可验证领域变聪明，其他领域会跟着免费变聪明。至少从笑话看，这种泛化没有以令人满意的程度发生。

所以他不信单一神谕模型的路会一直走下去。现在各家都在做单一模型，把所有能力塞进一套参数。他预期出现物种分化，像动物界，不同脑子各占一个生态位：保留认知内核的小模型，往具体任务上特化，比如专攻 Lean 定理证明的模型。分化的障碍他也点明了：动权重的科学还不成熟，微调容易弄丢别的能力，持续学习没有好用的原语，大家只会操作上下文窗口，因为便宜又安全。真碰权重，等于动整个模型的智力，没人敢乱来。

为什么不回前沿实验室，以及开源的位置

节目里 Sarah Guo 替一位在前沿实验室工作的听众诺姆（Noam）问了个尖锐问题：你完全可以带着 AutoResearch，和一群同事、一大堆算力，在实验室里干，为什么不？

Karpathy 的回答分两面。他去过，OpenAI 创始成员，后来回去过，又离开了。反面理由有三个。第一，利益结构拧着：你有巨大的财务激励，同时你亲口说 AI 会剧烈改变人类社会，你既造它又靠它赚钱，这个死结从 OpenAI 创立那天就在解，至今没解开。第二，你在里面没有完全的言论自由，有些话不能说，有些话组织希望你来说，没人扭你的胳膊，但你会感受到那种压力，不然聊天时会很尴尬，会有奇怪的眼神。第三，他觉得自己在实验室外面，反而跟全人类站在一边。

正面他也认账：实验室不透明，真东西在里面，在外面待久了，判断力一定会漂移，你会不知道铁轨往前铺到了哪里。他说自己也为此紧张，所以理想状态是进出自由，去实验室做一阵子真正的好工作，再出来。他还补了两句：眼下赌注还低，一切尚且温和，等真正高风险的时刻来临，一个雇员在房间里能有多少分量，他持怀疑态度；诺姆在 OpenAI 能做出极好的工作，但他影响最大的工作，很可能在 OpenAI 外面。

聊到开源，他给了一组数字：开源模型落后闭源的时间差，最早是 18 个月，现在收敛到大概 6 到 8 个月。他拿 Linux 类比，软件行业最终需要一个大家都敢用的开放平台，他记得大概六成的计算机在跑 Linux。差别在于训练模型的资本开支太大，开源很难正面竞争前沿。他的预期：闭源实验室做前头的神谕，开源吃掉大部分日常用例，今天的前沿，今年晚些时候可能就开源了。他甚至说，只有闭源智能一种选择，是有系统性风险的，权力集中这个东西，历史上记录很差。他还嫌前沿实验室太少，机器学习里集成模型几乎总好过单个模型，做最难决定的时候，他希望房间里人多一点。

比特光速，原子爬坡：工作、机器人与教育

他最近还发布了一版美国劳工统计局数据的分析，给每个职业标了未来十年的预期增速，再按数字工作还是物理工作上色，数据里最缺的是医护。他的框架很简洁：改一个比特比搬一个原子快一百万倍，数字世界会以光速重构，物理世界慢好几拍。先被重排的，是那些在家就能干、整天处理数字信息的职业。他把这轮变化叫「人类超个体神经系统的升级」。岗位变多还是变少，取决于需求弹性，但工作内容一定会重排。

工程岗的需求目前还在涨。他用杰文斯悖论解释：软件以前贵，需求被价格压着；成本塌下来，被压住的需求会涌出来。经典案例是 ATM 机，当年都怕柜员被机器取代，结果是开分行变便宜，分行开多了，柜员反而更多。他对软件工程谨慎乐观。

至于实验室研究员自己，他说了句扎心的：OpenAI、Anthropic 雇着上千名研究员，大家在干的事，是亲手把自己自动化掉。他真在 OpenAI 逛过一圈，跟同事说，咱们要是成功了，咱就都失业了，我们就是在给 Sam Altman 或者董事会造自动化。

机器人那部分，他的判断来自十年前的自动驾驶：当年一堆创业公司，长期看大多没活下来，这行吃资本、吃时间、吃信念。顺序他会这么排：先数字世界大解绑，再是数字与物理的接口，传感器和执行器，比如 Liam Fedus 的 Periodic Labs，用贵重实验设备当传感器做材料研究；最后才是物理世界本身，市场可能比数字世界还大，但会慢很多。纯数字的活总有干完的一天，读完全部论文之后，总得做实验问宇宙要答案。

他还提了个信息市场的缺口：预测市场里全是自动化交易，那德黑兰街头一张现场照片就该有人愿意出 10 美元买，买来喂给模型。传感器、执行器、数据买卖，这些接口层的位置，他认为是下一批好公司会出现的地方。

教育部分，他拿自己十年的执念项目开刀。新项目 microGPT，把训练一个 LLM 压到 200 行 Python，含注释：数据集是文本，网络结构 50 行，autograd 引擎 100 行，Adam 优化器 10 行，合成一个训练循环。以前他会录视频逐行讲，现在不讲了。讲给人听这一步可以省了：把代码讲给 Agent 听，Agent 能用任何语言、无限耐心、按对方的水平转述给任何人。

他的新做法：文档别再写给人类，HTML 换成 Markdown，写给 Agent。库的文档如此，课程也一样，他把教学路径写成 skill，让 Agent 按脚本带着人走。他试过让 Agent 从零写出 microGPT，写不出来；但 Agent 完全看得懂 microGPT，懂每一行为什么这么写。他自嘲，自己的贡献就剩那几个比特了。

最后是明天就能用上的清单：

  • 查一下自己的 token 吞吐量。订阅额度有剩余就该警觉，一个 Agent 在跑，就并行再开一个，别干等。
  • 把项目里反复出现的约定写进 AGENTS.md 并认真维护，那是你跟 Agent 的合同，写得越清楚，返工越少。
  • 挑一件有客观验收指标的活，试着让 Agent 通宵自己跑，早上验收。有标准答案的事，才轮得到自主循环。
  • 写文档时多想一层：这段话给人看，还是给 Agent 看？给 Agent 的那份，越早写越好。
  • 给自己做个体检：工作内容若全是可验证的数字信息处理，尽快把 Agent 接进流程；核心若在原子世界，短期反而占优。

Karpathy 在节目结尾的提醒，值得抄下来贴在屏幕边上：Agent 做不到的事，才是你的工作；Agent 能做的事，它很快会做得比你好。想清楚把时间花在哪，这是眼下最值钱的战略问题。
